# JD 面试冲刺总计划

状态：inbox 草稿，暂不落库。

## 目标

基于 `README.md` 中 Nirva 国内团队 Founding iOS Engineer JD，产出一套可直接用于 7 天冲刺的准备材料。准备目标不是「会背 iOS 面试题」，而是能把 **AI 可穿戴的 iOS 端从 0 到 1 扛起来**，并和深圳硬件 / 固件、硅谷软件 / 产品一起把设备交付出去。

答题一律走五层：`结论 -> 机制 -> 案例 -> 取舍 -> 指标/故障`。没有机制、没有证据、没有边界的回答，视为没准备。

## 这份 JD 真正想招的人

面试官大概率在验证四件事：

1. 你能不能独立扛起 iOS 客户端，而不只是写页面。
2. 你能不能把 App 和真实硬件设备稳定接起来，不怕联调。
3. 你能不能在 0 到 1 的模糊环境中快速推进，并建立工程秩序。
4. 你能不能和中美跨团队协作，把技术问题说清楚、推动落地。

## 面试优先级

### P0：必须准备到能连续回答

- Swift / iOS 基础：并发、内存、生命周期、后台任务、网络、存储
- Core Bluetooth：扫描、连接、发现服务与特征、订阅通知、写入、重连
- BLE 异常恢复：断连、超时、重复连接、状态同步、幂等处理
- 软硬件联调：问题归因、和固件团队共同验证
- 工程 ownership：版本规划、质量保障、日志、监控、CI/CD

### P1：强加分项

深挖见 `08`。

- OTA 失败路径、commit 点、防砖
- 低功耗：SLA、连接档、扫描/重连预算
- 离线数据同步：设备 seq、pending、冲突
- 音频采集或传感器数据面
- 启动 / 崩溃率 / 连接成功率如何定义和治理

### P2：差异化项

深挖见 `08`。

- EVT / DVT / PVT / 试产 / 量产翻译成客户端工作
- C/C++ 与硬件通信协议边界
- AI-native 工作流及其风险边界
- 英文技术沟通与跨时区书面同步

## 7 天执行节奏

### Day 1：JD 拆解与能力映射

- 精读 `01`
- 用 `02` 做自测，标出红线项和诚实缺口
- 选定 1 个旗舰故事，覆盖 BLE + 联调 + 交付

### Day 2：iOS 基础与工程体系

- Swift 并发、内存管理、生命周期、后台任务
- 模块化、日志监控、自动化测试、CI/CD
- 对应 `03` 模块 1–3、8

### Day 3：BLE / Core Bluetooth 深挖

- 连接全流程与状态机
- 脏场景：扫描不到、断连、超时、重复连接、前后台恢复
- 数据传输、状态同步、幂等
- 对应 `03` 白板 1、模块 4

### Day 4：软硬件联调 / 加分项深挖

- 联调分层归因
- `08`：低功耗、OTA commit/防砖、离线同步、音频或传感器
- `08`：C/C++ 协议边界，EVT 到量产客户端职责
- 对应 `03` 白板 2–4，以及 `08` 白板 5–8

### Day 5：项目故事库与行为面

- 把 `04` 的 `[人设案例]` 替换成自己的真实项目名和数字
- 准备 ownership / 0 到 1 / 高压排障

### Day 6：英文表达与半场模拟

- 用 `05` 做 90 秒介绍、项目讲述、风险同步
- 用双 Agent 跑一轮技术面 + 一轮英文

### Day 7：全链路串讲

- 按 `06` 跑四轮模拟
- 对照文末验收标准过一遍
- 准备反问面试官的问题

## 使用方式

1. 先读 `01` 和 `02`，明确面试官在看什么、自己缺什么。
2. 再用 `03` 补 P0 技术表达，能画白板 1–4。
3. 用 `08` 把加分项追问到机制：功耗、OTA、离线同步、传感器/音频、协议、量产阶段。
4. 用 `04` 把真实经历映射进 STAR；没替换前先用人设稿练结构。
5. 用 `05` 做英文 rehearsal。
6. 按 `06` 做整轮模拟：面试官一次一问，资深候选人按人设作答。
7. `07` 是 P0 口播稿；加分项口播以 `08` 为准。

## 验收标准

完成这套冲刺后，至少应达到：

- 能用 2 分钟讲清这份 JD 为什么适合你
- 能用 5 分钟讲清一条软硬件联调链路
- 能画出 BLE 连接 / 恢复状态机，并解释幂等
- 能讲启动、崩溃、连接成功率如何定义和治理
- 能讲功耗 SLA、OTA commit/防砖、离线 seq 同步，以及 EVT 到量产客户端在冻什么
- 能讲出如何用 AI 提升研发效率，以及不外包给 AI 的判断
- 能用英文完成自我介绍、项目介绍和一次风险同步
- 没做过的加分项有迁移话术，不硬装做过
