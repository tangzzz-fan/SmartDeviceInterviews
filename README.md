完整说明（启动、功能地图、**Markdown 同步约定**）：[docs/LEARNING_TRACKER.md](./docs/LEARNING_TRACKER.md)

```bash
# 后端
cd backend && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 导入综合版材料
python -m app.import_content

# 前端（另开终端）
cd web && npm install && npm run dev
```

打开 http://127.0.0.1:5173 。改 Markdown 后再次运行 `python -m app.import_content` 即可同步（进度按稳定 ID 保留）。

## 四套源材料的评估与取舍

| 来源 | 评估结论 | 在综合版中的角色 |
| --- | --- | --- |
| **DeepSeekV4/** | 覆盖面最全、结构最稳，答案主干可直接用；深度到「机制层」，缺 API 级细节 | **骨架**：答案主干、7 天计划、执行清单、STAR 骨架、加分项七专题 |
| **Composer2/** | 机制深度最好，诚实度最高；8 张白板图、缺口话术、五层答题结构是独家资产 | **机制深度**：白板图、Ready≠didConnect、断连三分类、诚实缺口话术 |
| **qwen3.8/** | API 与系统细节最深（State Restoration、MetricKit、吞吐公式）；模拟面试追问链最好 | **深度与验收**：bluetooth-central 后台、pairing/bonding、协议兼容四件套、模拟面评分体系 |
| **GPT5.4/** | 结构完整但大量模板化空话，数字与案例密度低 | **仅取零散补充**：英文会议句式、不确定性表达 |

四套原始材料保留在同级目录仅作追溯。

## 使用规则

1. **D1 先自评**：填完 02 的自评表再开始刷题，薄弱点决定优先级。
2. **脱稿复述才算会**：默读不算数；每题答完按 08 的单题检查表打勾。
3. **数字必须真实**：材料中标注「示范」的数字和【】占位是人设值，上场前全部替换为真实经历——面试官一定追问细节，编造会被识破。
4. **缺口不硬装**：没做过的项目用 02 的诚实缺口话术（承认边界 + 相邻经验 + 补法），不要虚构。
5. **D6–D7 录音模拟**：按 08 脚本跑全真模拟，平均分 < 4 的题回对应题库重练。
