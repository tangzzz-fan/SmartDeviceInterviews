# JD 面试冲刺总计划

## 目标

基于 `README.md` 中这份 Founding iOS Engineer JD，产出一套可直接用于 5 到 7 天冲刺的准备材料，覆盖以下 8 个核心维度：

1. iOS 基础功底
2. Swift 并发与内存
3. BLE / Core Bluetooth
4. 软硬件联调与 OTA
5. 性能、稳定性、后台与同步
6. 工程体系与交付
7. AI-native 研发方式
8. 英文沟通与 startup ownership

## 这份 JD 真正想招的人

这不是一个普通的 iOS 岗，而是一个带有明显创业公司特征的 `Founding iOS Engineer` 岗位。面试官大概率想验证四件事：

1. 你能不能独立扛起 iOS 客户端，不只是写页面。
2. 你能不能把 App 和真实硬件设备稳定接起来，不怕联调。
3. 你能不能在 0 到 1 的模糊环境中快速推进，并建立工程秩序。
4. 你能不能和中美跨团队协作，把技术问题说清楚、推动落地。

## 面试优先级

### P0: 必须准备到能连续回答

- Swift / iOS 基础：并发、内存、生命周期、后台任务、网络、存储
- Core Bluetooth：扫描、连接、发现服务与特征、订阅通知、写入、重连
- BLE 异常恢复：断连、超时、重复连接、状态同步、幂等处理
- 软硬件联调：如何定位问题归因，如何与固件团队共同验证
- 工程 ownership：版本规划、质量保障、日志、监控、CI/CD

### P1: 强加分项

- OTA 设计
- 低功耗优化
- 离线数据同步
- 传感器 / 音频 / 健康类设备经验
- EVT / DVT / PVT / 量产相关认知

### P2: 差异化项

- AI-native 工作流
- 英文技术沟通
- Founding 阶段的取舍与判断力

## 冲刺策略

### 原则

1. 不做泛泛复习，只围绕这个 JD 反推准备。
2. 不追求每个点都会写代码，优先做到每个点都能讲清楚。
3. 每个模块都要准备 `概念 -> 方案 -> 取舍 -> 故障案例 -> 指标` 五层表达。
4. 优先补齐短板，再包装优势。

## 7 天执行节奏

### Day 1: JD 拆解与能力映射

- 精读 JD
- 标出显性要求、隐性要求、红线项、加分项
- 完成差距地图

### Day 2: iOS 基础与工程体系

- Swift 并发、内存管理、生命周期、后台任务
- 模块化、日志监控、自动化测试、CI/CD

### Day 3: BLE / Core Bluetooth 深挖

- 连接全流程
- 常见异常与恢复策略
- 数据传输与状态机设计

### Day 4: 软硬件联调 / OTA / 性能

- 联调分工与问题归因
- OTA 升级链路
- 启动、内存、功耗、稳定性与后台同步

### Day 5: 项目故事库与行为面

- 复杂项目复盘
- 跨团队协作
- ownership / 0 到 1 / 高压排障案例

### Day 6: 英文表达与模拟面试

- 英文自我介绍
- 英文技术解释
- 英文风险同步

### Day 7: 全链路串讲

- 模拟电话筛
- 模拟技术一面
- 模拟深挖与反问

## 验收标准

完成这套冲刺后，你至少应该达到以下状态：

- 能用 2 分钟讲清这份 JD 为什么适合你
- 能用 5 分钟讲清一个软硬件联调项目
- 能解释 BLE 连接与异常恢复的完整链路
- 能回答 iOS 性能、后台、同步、稳定性相关追问
- 能讲出你如何用 AI 提升研发效率
- 能用英文完成基本自我介绍、项目介绍和风险同步
