## 4. 术语表（先扫一眼）

| 术语 | 一句话 |
| :--- | :--- |
| **model** | 学到的参数 + 计算图；本 lab 是小 MLP 三分类器 |
| **inference（推理）** | 用已训练模型对新输入算出输出（这里是 3 类概率） |
| **feature（特征）** | 模型输入向量；本 lab 固定 **8** 维 float |
| **label（标签）** | 训练时的正确答案；`rest` / `walk` / `run` |
| **MLP** | 多层感知机，最简单的神经网络（输入→隐藏→输出） |
| **MIL** | CoreML 的中间表示语言，类似 LLVM IR |
| **mlprogram** | CoreML 新格式，支持 FP16 精度控制 |
| **preprocess（预处理）** | 推理前对特征的变换（如 StandardScaler）；必须与训练一致 |
| **quantization（量化）** | 用更低精度（如 FP16）存算；本 lab 比 top-1 一致率，不比逐 logit |
| **`.mlpackage`** | Core ML 模型包（coremltools 导出），内含 Manifest + model + weights |
| **`.mlmodelc`** | 编译后的设备可执行产物；由 `compileModel` 生成 |
| **`compileModel`** | 把 package 编译成设备可执行的 `.mlmodelc`；应 **一次**，非每次推理 |
| **ANE** | Apple Neural Engine，苹果的专用神经网络加速芯片 |
| **fallback** | ANE 不支持某算子时，自动回退到 CPU/GPU |
| **PSI** | Population Stability Index，用于检测输入分布是否漂移 |
| **KL 散度** | 衡量两个概率分布差异的指标 |
| **top-1** | 概率最大的那一类；产品语义上的「预测结果」 |
| **confidence** | 通常指 top-1 对应的 softmax 概率 |
| **Session** | 编译+加载后的模型对象，可反复推理（本 lab 的核心 API） |
| **Actor** | Swift 并发隔离机制，保证数据安全的串行访问 |

| 路径 | 作用 |
| :--- | :--- |
| `python/generate_coreml_quant.py` | 训练 + 导出 FP32/FP16 |
| `python/explore_mlpackage_structure.py` | 交互式探索模型内部结构 |
| `artifacts/coreml/activity_fp32.mlpackage` | Swift / Python 共用的 FP32 模型 |
| `artifacts/coreml/activity_fp16.mlpackage` | FP16 对照模型 |
| `golden/coreml_quant/compare_report.json` | 指标、scaler、`verification_vectors` |
| `Sources/AlgoSwift/CoreMLActivityModel.swift` | Swift 加载与推理（Session 模式） |
| `Sources/AlgoSwift/CoreMLIntegrationPatterns.swift` | 三种集成模式演示 |
| `Sources/AlgoSwift/CoreMLStreamingPipeline.swift` | 流式滑窗推理 + Actor |
