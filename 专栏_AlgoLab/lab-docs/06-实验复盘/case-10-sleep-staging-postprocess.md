# Case10 实验复盘：睡眠分期后处理

版本：0.1.0 · 日期：2026-07-28 · 作者：lab · 状态：草稿

## 1. 假设
- 单 epoch 直接 argmax 会产生抖动，影响 hypnogram 可读性。
- 轻量规则后处理即可显著降低“单点跳变”。

## 2. 做法
- Python 先实现两步规则：majority3 + singleton 折叠，生成 golden。
- Swift 同构实现，输出 raw/smoothed 与统计指标（TST、SOL）。
- 数据集覆盖正常、抖动、短序列与空输入。

## 3. 数字
- 数据集：33 条，病态占比 > 60%。
- 断言：raw/smoothed 序列逐点一致；TST/SOL 指标数值一致。

## 4. 坑
- 规则顺序会影响结果；先 majority 再 singleton 与反向顺序不同。
- 只看最终指标会掩盖路径差异，必须保留 raw/smoothed 快照。

## 5. 结论
- 后处理应被当作独立算法模块并进入 parity 回归，不是 UI 层临时修饰。

## 6. 面试卡片（≤5）
- 我把睡眠分期后处理拆成可复现规则链路并固化 golden。
- 不只对指标，还对中间序列做逐点对齐，方便定位漂移。
- 这类后处理在产品里直接影响可解释性与用户信任。
