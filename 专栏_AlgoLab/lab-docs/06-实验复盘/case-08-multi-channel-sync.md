# Case08 实验复盘：多通道同步与漂移校正

版本：0.1.0 · 日期：2026-07-28 · 作者：lab · 状态：草稿

## 1. 假设
- 多通道在 BLE 分片下会因为漂移/乱序/丢包造成对齐误差。
- 统一参考时基 + 序列号重排能恢复可分析时间轴。

## 2. 做法
- Python 作为真值：按 `seq` 排序后将样本映射到 `idx = round(t/dt_ref)`。
- 构造 3 类样本：正常、漂移、漂移+丢包+乱序。
- Swift 同构重建，输出 `timeline/aligned/mask` 与 golden 比对。

## 3. 数字
- 数据集：33 条（病态 > 60%）。
- 断言：`timeline` abs≤1e-12、`aligned` abs≤1e-9、`mask` 逐点一致。

## 4. 坑
- 映射若使用 floor 而非 round，会引入系统性相位偏移。
- 只重建波形不输出 mask，会丢失“缺口来自丢包还是有效 0 值”的语义。

## 5. 结论
- 多通道同步要把“时间重建”当作独立可验证模块，不应散落在业务层。

## 6. 面试卡片（≤5）
- 我把多通道同步拆成可回放算法，并用 golden 锁定时间轴语义。
- 漂移/丢包/乱序都可复现，先重建时间，再谈特征计算。
- `mask` 是工程上必需输出，保证后续算法知道哪些点是填补值。
