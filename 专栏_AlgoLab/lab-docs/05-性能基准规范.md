## 1. 基准环境记录格式（五项缺一无效）

| 字段 | 示例 |
| :--- | :--- |
| 机型 | MacBook Pro 14-inch 2023 |
| 芯片 | Apple M2 Pro |
| OS / iOS | macOS 15.x / iOS 18.x |

---

## 2. 指标定义

| 指标 | 定义 | 测量方法 |
| :--- | :--- | :--- |
| 耗时 p50 / p95 | 同一输入重复 N≥30 次的分位数 | XCTest `measure` 或 BenchmarkTests 自写循环；丢掉预热 3 次 |
| 内存峰值 | 任务区间内 dirty 峰值 | Instruments Allocations 或 `os_proc` 采样（注明） |
| 单位吞吐 | 样本/秒 或 窗口/秒 | 总样本数 / 墙钟时间 |
| 能耗/热状态 | 测试期间功耗与热节流状态 | Activity Monitor + 电池状态 + 机身温感（主观） |

禁止只报单次耗时。

## 4. 防退化门槛

同环境回归：**p50 恶化 >20%** 必须在提交说明中解释，否则视为事故。

建议落地方式：

- 在 BenchmarkTests 输出中保留上次基线（或读 `bench-log` 手动比对）
- 每次追加日志时明确“基线 commit”
- 若恶化超过 20%，在 commit message 或复盘中说明原因（算法变更、机器热态、样本变化等）

---

## 5. 精度与性能分离

- ParityTests：只断言精度，CI 必过。
- BenchmarkTests：只记录性能，**不**阻塞 CI（可本地/手动跑）。
- 优化版与 naive 版必须过**同一套** golden；「优化不许改变行为」。
