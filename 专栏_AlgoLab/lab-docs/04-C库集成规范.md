# 04 · C 库集成规范

版本：0.1.0 · 日期：2026-07-28 · 作者：lab · 状态：草稿

> Swift↔C 边界的一切规则。未覆盖的新模式必须先补本规范再写实现。

---

## 1. 职责边界

| 层 | 做 | 不做 |
| :--- | :--- | :--- |
| **AlgoC** | 纯数值计算；明确错误码；可重入声明见第 6 节 | I/O、日志、分配策略隐藏、线程创建 |
| **AlgoSwift** | 生命周期、`AlgoError` 翻译、队列调度、Unsafe 边界包装 | 在 Swift 里偷偷改算法口径 |

---

## 2. 内存所有权

1. **谁分配谁释放**：Swift 分配输入缓冲并在调用期间保持有效；C 不 `free` 调用方指针。
2. 输出：优先由调用方预分配输出缓冲，C 只写入；若 C 必须分配，提供配对 `algo_*_free`。
3. **禁止**返回指向 C 内部静态缓冲的指针给 Swift 长期持有。

---

## 3. 零拷贝约定

- 使用 `UnsafeBufferPointer` / `UnsafeMutableBufferPointer` 包裹连续存储，直接传 `baseAddress`。
- **禁止**在热路径上逐元素 `append` 到 `[Float]` 再拷进 C。
- 允许拷贝的例外：输入来自非连续 `Data` 切片、或需要对齐到 SIMD 要求时——须在 call site 注释原因。

---

## 4. 调用批次

- 按帧 / 按窗口批量调用；**禁止**逐采样点跨 Swift↔C 边界。
- 建议粒度：PPG/滤波 **1 秒窗口**或对齐口径中的 `window_size`；HRV 一次传入整段 RR 数组。

---

## 5. 错误码表

| 码 | 符号 | Swift `AlgoError` |
| ---: | :--- | :--- |
| 0 | `ALGO_OK` | — |
| 1 | `ALGO_ERR_EMPTY` | `.empty` |
| 2 | `ALGO_ERR_TOO_SHORT` | `.tooShort` |
| 3 | `ALGO_ERR_NON_FINITE` | `.nonFinite` |
| 4 | `ALGO_ERR_NULL_POINTER` | `.nullPointer` |
| 5 | `ALGO_ERR_INVALID_ARG` | `.invalidArgument` |

C API 返回 `int` 错误码；成功时输出经指针写出。

---

## 6. 线程模型

| 声明 | 约定 |
| :--- | :--- |
| 默认可重入 | 无可变全局状态的纯函数可并发 |
| 带状态的流式滤波器 | **不可**并发；同一实例仅在单一串行队列调用 |
| 允许队列 | 后台 `Utility` / 自定义 serial；勿在主线程跑重 DSP |
| 禁止 | 在 C 内开线程；在 signal handler 中调用 |

---

## 7. 头文件与模块

- 公共头文件置于 `Sources/AlgoC/include/`。
- SPM `target(name: "AlgoC", publicHeadersPath: "include")`。
- Swift `import AlgoC`（或通过 bridging 目标名以 Package 为准）。
