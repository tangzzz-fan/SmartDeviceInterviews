来源：父目录仓库 [`algo_lab`](../../algo_lab)（AxiLab / 智能穿戴算法工程化面试材料）。

## 与本站关系

- **独立栏目**：文档 ID 形如 `algolab:prep/01_BLE_...`，**不**与 Nirva 题库 `A1`/`B1` 混用。
- **岗位差异**：本专栏偏 AxiLab（HRV / CoreML / OTA DFU / 数值一致性）；`综合版/` 仍是 Nirva Founding iOS 主线。
- **可运行代码**：精简副本在 `labs/algo-engineering-lab/`（已排除 `.build` / `.venv`）。
