// 病根诊断（改写动机）：
// ① 状态存三份（属性），UI 存一份（控件），靠人肉同步维系一致——这就是命令式的税。
// ② 状态没有所有权概念：控制器什么都拿，谁都能改。
// ③ 交互入口是 target-action 回调，逻辑埋在回调里，读代码要跳来跳去。
// 翻译目标：状态唯一化（UI = f(state)），所有权按包装器声明，交互=改状态。
