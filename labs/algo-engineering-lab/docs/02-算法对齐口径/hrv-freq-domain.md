# 对齐口径：HRV 频域（LF / HF）

版本：0.1.0 · 日期：2026-07-28 · 作者：lab · 状态：生效

> Case3。链路最长；**每一环都有快照**。跨平台对不上时先查快照，不要先怪 FFT。

---

## 1. 环节分解表

| 环节 | 参数 | 取值 | Python | C / Swift |
| :--- | :--- | :--- | :--- | :--- |
| 输入 | RR | ms，float64；**不做伪差校正** | list | `const double *` |
| 最小长度 | N | ≥ **16** 个 RR | 否则 too_short | `ALGO_ERR_TOO_SHORT` |
| 时间轴 | t | \(t_0=0\)，\(t_{i}=t_{i-1}+RR_{i-1}/1000\)（秒） | 手写 | 同左 |
| 重采样 | fs | **4 Hz** 线性插值到均匀网格 | `np.interp` | 线性插值 |
| 去趋势 | — | **减均值**（不设线性斜率） | `x - mean(x)` | 同左 |
| 加窗 | — | **Hann**，`w[n]=0.5-0.5\cos(2\pi n/(N-1))`，N≥2 | 手写 | 同左 |
| FFT | — | **rFFT**；`numpy.fft.rfft` **不做 1/N** | `np.fft.rfft` | 朴素 DFT 实数半谱（同定义） |
| 功率 | — | \(P[k]=|X[k]|^2 / N^2\) | 同左 | 同左 |
| 频率轴 | — | `k * fs / N`，k=0..N/2 | `rfftfreq` | 同左 |
| LF | Hz | **[0.04, 0.15]** 含边界 | trapz | 梯形积分 |
| HF | Hz | **[0.15, 0.40]** 含边界；0.15 只计入 HF 一次 | trapz | 同左（LF 用 &lt;0.15，HF 用 ≥0.15） |
| 输出 | — | `lf`, `hf`, `lf_hf_ratio=lf/hf`（hf=0 则 ratio 记为错误 invalid） | — | — |

**边界约定（避免 LF/HF 双计）：**  
- LF：`0.04 ≤ f < 0.15`  
- HF：`0.15 ≤ f ≤ 0.40`

---

## 2. 中间快照

| 快照名 | 内容 | 比对阈值 |
| :--- | :--- | :--- |
| `resampled` | 4Hz 插值后序列 | abs ≤ 1e-9 |
| `detrended` | 减均值后 | abs ≤ 1e-9 |
| `windowed` | Hann 后 | abs ≤ 1e-9 |
| `psd` | \(P[k]\) 半谱 | abs ≤ 1e-9 或相对 ≤ 1e-12（朴素 DFT vs numpy.fft） |
| `lf` / `hf` / `lf_hf_ratio` | 标量 | LF/HF abs 相对 ≤ 1% 或 abs≤1e-6（取宽松者）；ratio abs ≤ 0.01 |

快照写入 golden 的 `snapshots` 字段；Parity 测试逐环断言，失败即报告**哪一环先偏**。
