# 01 · 数值一致性规范

版本：0.1.0 · 日期：2026-07-28 · 作者：lab · 状态：草稿

> 全项目唯一的精度与单位口径来源。Case 内禁止私自定义阈值或单位。

---

## 1. 浮点策略表

| 层级 | 类型 | 理由 |
| :--- | :--- | :--- |
| 存储层（golden JSON / 落盘） | 十进制文本或 float64 JSON number | 避免二进制往返歧义；golden 由 Python float64 生成 |
| 中间计算（累加、差分平方和、滤波卷积累加） | **double** | 累加类指标（如 RMSSD）在 float32 上会系统性放大误差 |
| 输出层（对外 API / 模拟嵌入式侧） | float（float32）或 double 按对齐口径文档指定 | 默认：指标输出用 double 做 parity；若对齐嵌入式 float 输出，在 case 口径中显式声明 |

---

## 2. 误差阈值表

| 指标 | 阈值 | 阈值依据（产品无意义量级） |
| :--- | :--- | :--- |
| SDNN (ms) | abs ≤ 0.1 ms | 短时 HRV 解读粒度通常远粗于此 |
| RMSSD (ms) | abs ≤ 0.1 ms | 同上；且对差分平方累加敏感，中间必须用 double |
| pNN50 (%) | abs ≤ 0.5 百分点 | 计数比指标，半个百分点以下无临床/产品意义 |
| FIR 滤波输出样本 | abs ≤ 1e-4（相对满幅归一化信号）或 case 口径另定 | 听感/波形显示无感量级；系数导出位数不足时会系统性超标 |
| LF / HF 功率 | 相对误差 ≤ 1% 或 case 口径 | 频带积分边界与窗函数差异通常大于该量级时需记入「已知差异」 |
| CoreML top-1 一致率 | ≥ 99%（相对 FP32 参考） | 分类任务看决策一致性而非逐 logit |
| 置信度分布 | 均值偏移记入报告，不设硬失败除非 case 声明 | FP16 常改变置信度形状 |

未列出的新指标：先改本表，再写实现。

## 3. 病态输入处理约定

| 输入 | 行为 |
| :--- | :--- |
| 空数组 | 返回错误码 `ALGO_ERR_EMPTY`；不抛异常穿过 C 边界 |
| 单点 / 长度不足以定义指标 | 返回 `ALGO_ERR_TOO_SHORT` |
| 含 NaN / Inf | 返回 `ALGO_ERR_NON_FINITE`；禁止静默传播到「看起来合法」的数值 |
| 极端值（如 RR &lt; 200ms 或 &gt; 2000ms） | 按该算法对齐口径做伪差剔除或拒绝；默认**不**在通用层吞掉 |
| 全零 / 常数序列 | 允许计算；若标准差为 0，输出按口径（SDNN=0 合法） |

Swift 侧将错误码映射为 `AlgoError`（见 `docs/04`）。

---

## 4. 单位与时间戳约定

| 量 | 单位 | 说明 |
| :--- | :--- | :--- |
| RR 间期 | **毫秒 (ms)** | 输入输出一律 ms，禁止混用秒 |
| 采样率 | **Hz** | 同时可派生采样间隔 `dt = 1/fs` 秒 |
| 频率（LF/HF 边界） | Hz | 0.04–0.15 / 0.15–0.4 |
| 时间戳 | 文档与日志用 wall clock；算法输入优先相对索引或 boot-relative 秒 | 跨端对账时显式声明基准 |

跨语言必须同一单位；转换只允许发生在明确的 adapter 层，并在对齐口径中写明。
