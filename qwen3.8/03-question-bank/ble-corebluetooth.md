# 题库：BLE / Core Bluetooth 专项

> 对应 JD：设备配对、连接管理、状态同步、数据传输、异常恢复、OTA。岗位差异化核心，必出系统设计题。
> 难度：★ 基础 / ★★ 进阶 / ★★★ 资深 / ★★★★ 系统设计

## Q1. 讲一遍 BLE 设备从扫描到数据收发的完整链路。
- **难度**：★★
- **考察意图**：BLE 全链路认知，CBCentralManager / CBPeripheral 的使用时序。
- **追问方向**：扫描到连接之间的回调顺序？服务与特征值发现流程？连接参数（interval/latency/timeout）如何影响功耗与延迟？

## Q2. CBCentralManager 的状态机有哪些状态？状态切换时你的 App 该怎么处理？
- **难度**：★★
- **考察意图**：Core Bluetooth 状态管理的真实开发经验。
- **追问方向**：poweredOff 时用户正在传数据怎么办？unauthorized/unsupported 如何引导用户？初始化时异步拿到状态前如何设计 API？

## Q3. 设备连接不稳定、频繁断连，你会怎么设计重连与恢复机制？
- **难度**：★★★
- **考察意图**：JD 明确提到"异常恢复"，这是可穿戴 App 的日常痛点。
- **追问方向**：重连退避策略怎么定？connect 带 retrievePeripherals 和 known devices 的区别？断开原因如何区分（用户主动/超距/设备关机）？

## Q4. iOS 后台 BLE 有哪些限制？App 进后台后如何维持设备通信？
- **难度**：★★★
- **考察意图**：JD"后台运行"要求 + 可穿戴场景核心难题，区分真做过与看文档的题。
- **追问方向**：bluetooth-central 后台模式能做什么不能做什么？state preservation & restoration 怎么实现？后台被杀后连接状态如何恢复？

## Q5. 设计一个固件 OTA 升级方案。
- **难度**：★★★★
- **考察意图**：JD 职责第 2 条明确点名 OTA，本岗位最高频系统设计题。
- **追问方向**：分包大小怎么定？校验用 CRC 还是哈希？断点续传怎么做？升级中断如何防变砖（A/B 分区）？要不要做灰度？升级失败如何回滚？

## Q6. BLE 传输吞吐量受限，大批量数据（如一天的传感器数据）怎么高效同步？
- **难度**：★★★
- **考察意图**：JD 加分项"传感器数据处理"，考察对 BLE 带宽的工程化理解。
- **追问方向**：MTU 协商机制？Connection Interval 对吞吐的影响？要不要设备端先压缩？如何估算同步时长并给用户预期？

## Q7. 设备配对（pairing/bonding）与连接（connection）有什么区别？iOS 上怎么处理？
- **难度**：★★
- **考察意图**：概念清晰度，很多候选人把配对和连接混为一谈。
- **追问方向**：iOS 不暴露配对 API 意味着什么？bonding 信息存在哪？用户删除设备后 App 侧如何感知？加密连接的 MITM 防护？

## Q8. App 和设备需要保持状态同步（电量、模式、固件状态），你的方案是什么？
- **难度**：★★★
- **考察意图**：JD 职责第 2 条"状态同步"，考察分布式状态一致性思维。
- **追问方向**：以谁为准？冲突怎么解？notify/indicate 怎么选？重连后全量同步还是增量？版本号/时间戳策略？

## Q9. 蓝牙协议栈大致分几层？GATT、ATT、L2CAP 各是干什么的？
- **难度**：★★
- **考察意图**：协议理解深度，能否和嵌入式团队在同一语言层对话。
- **追问方向**：GATT 的 service/characteristic/descriptor 模型？indicate 和 notify 的差别？CoC L2CAP 信道用过吗？

## Q10. 如何保证 BLE 通信协议的前后兼容（App 和固件版本不一致时）？
- **难度**：★★★
- **考察意图**：JD"与嵌入式团队定义通信协议"的工程化思维，量产产品的真实问题。
- **追问方向**：协议版本号放哪？能力协商（capability negotiation）怎么做？新 App + 旧固件 / 旧 App + 新固件四种组合怎么覆盖？

## Q11. 你在 BLE 开发中遇到过的最难的 bug 是什么？怎么定位的？
- **难度**：★★★
- **考察意图**：实战深度验证，没有 BLE 经验时的诚实度与迁移能力测试。
- **追问方向**：用了什么工具（PacketLogger、nRF Connect、Wireshark + sniffer）？时序问题怎么复现？和固件团队如何分工排查？

## Q12. 如果设备同时被多个 App/系统组件抢占连接，你怎么处理？
- **难度**：★★★
- **考察意图**：真实世界复杂场景，考察对 iOS 蓝牙资源竞争的理解。
- **追问方向**：iOS 同一时刻只能有一个 central 连接设备吗？和其他 App 竞争怎么办？AirPods 类产品系统级劫持的场景？
