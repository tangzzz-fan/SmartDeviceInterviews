# 题库：加分项专项（低功耗 / OTA 进阶 / 离线同步 / 音频与传感器 / 嵌入式 / 量产）

> 对应 JD 加分项两条：
> 1. 熟悉低功耗优化、设备 OTA、离线数据同步、音频采集或传感器数据处理。
> 2. 了解 C/C++、嵌入式系统或硬件通信协议，参与过 EVT、DVT、PVT、试产或量产交付。
> 本模块与 `ble-corebluetooth.md`、`performance-infra.md`、`hw-sw-collaboration.md` 有交叉，但聚焦更深的专项细节——面试官在基础题答得好时，会从这里继续深挖。
> 难度：★ 基础 / ★★ 进阶 / ★★★ 资深 / ★★★★ 系统设计

## 一、低功耗优化

### Q1. BLE 常连场景下，App 侧功耗优化的完整手段有哪些？
- **难度**：★★★
- **考察意图**：比"性能模块 Q3"更深一层，考察对 BLE 功耗模型的体系化理解。
- **追问方向**：扫描占空比与过滤策略？connection interval/latency 参数怎么权衡延迟与功耗？如何量化验证优化效果（Energy Log、设备侧电流仪）？

### Q2. 设备端低功耗你了解多少？能和固件团队讨论哪些话题？
- **难度**：★★★
- **考察意图**：考察跨端对话能力——App 工程师是否理解设备侧功耗构成。
- **追问方向**：设备睡眠/唤醒策略、传感器采样 duty cycle、BLE 广播间隔与功耗关系？App 哪些行为会拖累设备续航（频繁读特征值、保活心跳）？

## 二、设备 OTA 进阶

### Q3. OTA 的签名校验与安全机制怎么设计？业界常见的 DFU 方案你了解哪些？
- **难度**：★★★
- **考察意图**：OTA 基础题（BLE Q5）答好后的进阶追问，考察安全与行业视野。
- **追问方向**：固件签名（ECDSA/RSA）在哪个环节验证？防回滚（anti-rollback）怎么做？Nordic DFU、mcumgr/SMP 这类方案的核心思路？

### Q4. 产品量产后 OTA 大规模推送，会遇到什么新问题？
- **难度**：★★★★
- **考察意图**：从"单机 OTA"到"fleet 管理"的思维跃迁，量产产品的真实挑战。
- **追问方向**：分批次灰度与熔断机制？升级成功率怎么埋点统计？用户弱网/低电量时如何择机？紧急安全漏洞时的强制升级策略？

## 三、离线数据同步

### Q5. 设备→手机→云三段链路的离线同步，如何保证最终一致与不丢数据？
- **难度**：★★★★
- **考察意图**：比"性能模块 Q8"更聚焦一致性设计，可穿戴产品的数据生命线。
- **追问方向**：每段的持久化边界在哪？手机重装 App 后设备数据如何找回？同步位点（checkpoint）怎么设计？

### Q6. 同步协议的幂等、去重与断点恢复具体怎么实现？
- **难度**：★★★
- **考察意图**：协议级工程细节，区分"知道概念"与"实现过"。
- **追问方向**：事件 ID 与序列号怎么选？时间戳冲突（设备时钟不准）怎么处理？半包写入如何避免脏数据？

## 四、音频采集与处理

### Q7. iOS 音频采集的技术要点：AVAudioSession 与 AVAudioEngine 怎么用？
- **难度**：★★★
- **考察意图**：JD 加分项"音频采集"，AI 可穿戴产品大概率涉及语音输入。
- **追问方向**：category/mode 怎么选？电话来电等中断（interruption）如何恢复？采样率/格式与功耗的权衡？后台录音的权限与限制？

### Q8. 音频类可穿戴设备的音频数据链路怎么设计？
- **难度**：★★★★
- **考察意图**：音频 over BLE 的工程现实与取舍，考察产品级方案设计。
- **追问方向**：BLE 带宽下能传实时音频吗（LE Audio/LC3 了解吗）？录音存设备端再回传 vs 实时流的取舍？音频唤醒词检测放端侧还是云端？

## 五、传感器数据处理

### Q9. 传感器数据（加速度、心率等）在端上怎么处理？
- **难度**：★★★
- **考察意图**：JD 加分项"传感器数据处理"，考察数据管道设计能力。
- **追问方向**：Core Motion / 第三方 SDK 的采集模型？采样率怎么选？端上滤波（低通/滑动平均）与聚合降采样的时机？

### Q10. 大量时序健康数据（如 7×24 心率）的存储、查询与展示怎么做？
- **难度**：★★★
- **考察意图**：数据量级带来的工程问题，存储选型与 UI 性能的交叉点。
- **追问方向**：SQLite 时序表怎么设计索引？图表渲染大数据量怎么降采样（LTTB 之类）？HealthKit 要不要接？
