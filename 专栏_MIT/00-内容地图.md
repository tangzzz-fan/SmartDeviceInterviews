# 内容地图：四条 MIT 学习线（main = 全量归档）

> main 是「教练侧全量归档」：所有学习内容（出题、密卷、作答、批改、费曼、代码、文档）都在这里，可直接搜索/点击查询。

> 命名规律：`T{轮次}-{01出题/01密卷/02作答/03批改/04费曼}-{主题}.md`。

## 〇、三个视图

| 视图 | 位置 | 内容 | 用途 |
|------|------|------|------|
| **学员侧** | `.worktrees/*-student`（各线学员分支） | Swift/Python：题干+骨架（闭卷）；设计模式/CoreML：**三处齐全**（题干+密卷+参考解法+示例批改/费曼） | 练：闭卷作答、代码实跑（三处齐全线为自律模式：先写后对照） |
| **教练侧** | `.worktrees/*-coach`（各线教练分支） | 全量：题干+密卷+批改/费曼+解法+台账 | 判/答：出题、判卷、逐级提示 |
| **全量参考** | `main` | 四线全量 + README + 本内容地图 | 查：归档、跨线索引 |

## 二、main 如何保持全量

1. 学员分支提交 `T{n}-02 作答` 与 `T{n}-04 费曼`（学员侧产出）；
2. 教练分支 merge 学员分支阅卷，产出 `T{n}-03 批改与判定` 并更新台账；
3. 教练分支并入 main（`git checkout main && git merge <教练分支>`）——main 随进度长全；
4. 设计模式/CoreML 为三处齐全（先闭卷后对照）；Swift/Python 学员侧保持闭卷（密卷/批改/代码在教练侧与 main）。
