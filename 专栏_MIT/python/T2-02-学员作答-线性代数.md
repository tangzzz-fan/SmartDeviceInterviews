## 〇、五模型自推（先写再对本）

我的自推版本：① 向量就是数组/特征列表；② 矩阵乘法 = 三重循环算出来的东西；③ 矩阵能把点变换位置；④ 特征值好像是「矩阵自带的某种关键数字」，PCA 要用；⑤ SVD 听说过，能把矩阵拆成三块，可以做压缩。

对教练版后的差异标注：M1 我漏了「方向/几何」这副面孔，只想到数据；M2 我只剩「行×列怎么算」这一副眼镜，列组合和变换视角是看了题干才想起来的；M3 我说「能变换位置」但说不出「列是基向量的去向」这个机制；M4/M5 基本是名词级记忆。复习线的病和 T1 一样：API 记得住，模型记不住。

## 一、概念口述通道

**C1（三重解释）**：① 行内积视角我有把握：C[i][j] 就是 A 的第 i 行和 B 的第 j 列逐位相乘再求和。列组合视角题干一提我能接上：A@v 应该是 A 的几列按 v 的分量加权加起来——这么看 C 的每一列确实是 A 的列空间的点。变换视角我只能说到「B 把向量搬到一个新位置，A 再搬一次」。② C 的第 j 列为什么只由 B 的第 j 列决定：按列组合视角，算第 j 列时只用到 B 的第 j 列当权重，A 的所有列都参与但 B 的其它列不参与。③ 交换律反例：我猜旋转和某个操作换顺序结果不同，现场写不出严谨的 2×2 数字例。自评：**半懂半猜**（①②能讲，③只有方向没有例子）。

**C2（列=基向量去向）**：① 现场算：A@(1,0)ᵀ 按定义乘一遍，结果就是 A 的第一列；(0,1) 同理得第二列。这个我能当场演示，因为就是矩阵乘法的定义。但「为什么整个变换由基向量去向唯一确定」我得想一下：任何向量是基向量的组合，线性变换保组合，所以知道基去哪就知道一切去哪——写得出来但不算熟。② 奇异矩阵：我会答「不可逆、行列式为 0」。几何上干了什么……我猜是把空间压扁了？和投影的关系说不清。自评：**半懂半猜**。

**C3（特征分解与 PCA）**：① 定义 Av = λv 我记得：作用后方向不变只缩放 λ 倍，这个能讲。② 为什么 PCA 取最大特征值方向：我只背过「第一主成分是方差最大的方向」这个结论，从「投影后方差最大」推到「Cw = λw」这一步我推不动，感觉要拉格朗日但手推不出来。③ 凭什么有实特征值且正交：协方差矩阵是对称的，对称矩阵好像有这个性质——定理名字在嘴边但说不严谨。自评：**半懂半猜**（①对，②③断链）。

**C4（SVD）**：① U、Σ、Vᵀ 的几何角色：Σ 是对角阵负责缩放我确定；U、V 是不是旋转？大概一个转输入一个转输出，顺序和方向我吃不准。② 奇异值排序：API 返回就是降序的……为什么「天然」排好我没想过，猜是每次取剩余里最大的方向？③ 截断为什么最优：直觉上「丢掉不重要的当然损失最小」，但为什么「正交分量互不干扰、误差等于丢弃项平方和」讲不出来。自评：**纯猜**（纯学习区，只有 API 级印象）。

**C5（形状推导）**：① (N,D)@(D,K) = (N,K)，内维 D 相消留下 N 和 K；b 是 (K,)，加到每行上——广播我理解成「小形状自动扩展到大的」，尾部对齐这个说法是第一次说。② W@X 要求 W 的列数 K 等于 X 的行数 N，一般不成立。③ 列主存放 X' 是 (D,N)：我第一反应是转置 X' 再按行主算，写下来发现 Y' 应该直接是 (K,N)，公式是 Wᵀ@X'，转置挂在 W 上——推了两遍才敢写。④ 链：X(N,D)@W1(D,H)=(N,H)，再 @W2(H,K)=(N,K)。自评：**有把握**（①②④顺，③推了两遍才落地）。

**C6（神经网络桥接）**：① 前向 = 每层 Wx+b 再过一个逐元素激活；没有非线性的话，两层 W2(W1x) 结合律合成一个矩阵，十层也是——这个我能推，矩阵乘法满足结合律。② 对角矩阵变式：对角阵乘对角阵还是对角阵……那就是说每个特征各乘各的，特征之间完全不交互？这个结论我是现场推的，不确定对不对。③ 硬件为什么快：我类比 iOS 里 Accelerate/SIMD 的经验——内积是规整的乘加循环，一条向量指令能算好几个乘加，内存访问也是连续的——这是类比推理不是亲历，算猜。自评：①**有把握**，②**半懂半猜**，③**半懂半猜**。
