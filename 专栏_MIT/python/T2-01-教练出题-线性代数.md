## 一、共识模型（教练版五个骨架）

学员先自推五模型再对本版，标注差异。

| # | 模型 | 一句话骨架 |
|---|------|-----------|
| M1 | 向量是「数据 + 方向」的双重身份 | 一行样本、一列特征是同一个对象的两副面孔；维度不是玄学，是特征个数 |
| M2 | 矩阵乘法有三重解释 | ① 行×列内积（元素怎么算）② 列组合（结果的每列是左矩阵列的加权组合）③ 线性变换（把输入向量搬到新位置）；三副眼镜换着戴 |
| M3 | 矩阵 = 线性变换，列是基向量的去向 | 矩阵的第 j 列就是「第 j 个基向量被变换后落到哪里」；变换可逆 ↔ 信息没丢；降秩 = 压扁到低维 = 信息丢失 |
| M4 | 特征分解找「变换中不转向的方向」 | 特征向量是被变换后只被拉伸、不被转向的方向，特征值是拉伸倍数；协方差矩阵的特征向量 = 数据方差最大的方向（PCA 的根） |
| M5 | SVD：任何矩阵 = 旋转 × 拉伸 × 再旋转 | 奇异值 = 各个正交方向上的「重要性」，按大小排好队；截断前 k 个奇异值 = 最优低秩近似（压缩/降噪的数学根基） |

## 二、争议焦点（三题，考有边界的立场）

- **F1**：「学线代应该从矩阵运算入手（工程派）」vs「应该从线性变换/几何直觉入手（3Blue1Brown 派）」——你站哪边？对你这种工程老手复习，哪条路更快、各自的代价是什么？
- **F2**：神经网络代码该不该「一切转成批量矩阵乘法（GEMM）」？GPU 友好论的边界在哪里——什么情况下显式循环/逐元素操作反而是对的？
- **F3**：实现 PCA 用「协方差矩阵特征分解」还是「对数据直接 SVD」？教学直观与数值稳定各站哪边，生产代码你选哪个、为什么？

## 三、拷问题——概念口述通道（C1–C6）

**C1（M2）**：矩阵乘法的三重解释——① 分别用「行内积」「列组合」「线性变换」三副眼镜解释 C = A@B 的含义；② 为什么 C 的第 j 列只由 B 的第 j 列决定？③ 为什么矩阵乘法不满足交换律？给一个 2×2 的几何反例（不许只说「维度对不上」）。

**C2（M3）**：「矩阵是线性变换」的机制层拷问——① 为什么说矩阵的列就是基向量的去向？用 2×2 矩阵作用于 (1,0)、(0,1) 当场演示；② 奇异（不可逆）矩阵在几何上干了什么？它和「信息丢失」「降维投影」是什么关系？

**C3（M4）**：特征分解三连——① 特征值/特征向量的定义式与几何含义；② 为什么 PCA 找的是协方差矩阵最大特征值对应的特征向量？不许只背结论，要从「投影后方差最大」推到「特征向量」这一步；③ 协方差矩阵凭什么保证有实特征值、且特征向量正交？

**C4（M5）**：SVD 三连——① A = UΣVᵀ 中 U、Σ、Vᵀ 各自的几何角色是什么？② 奇异值为什么天然排好序、为什么能衡量「重要性」？③ 为什么只保留前 k 个奇异值的低秩近似是「最好的」近似？直觉必须给，知道 Eckart–Young 定理可以提但定理名字不算分。

**C5（M2，形状推导）**：批次数据 X 形状 (N, D)，权重 W 形状 (D, K)，偏置 b 形状 (K,)——① 写出 Y = X@W + b 的形状并逐维说明为什么能广播；② 为什么 W@X 不合法？③ 若数据按列存放 X' 形状 (D, N)，公式要怎么改写（转置放哪里）？④ 三层串联 X→W1(D,H)→W2(H,K) 的中间形状链写全。

**C6（M2/M3，桥接神经网络）**：① 为什么神经网络前向传播的本质是「矩阵乘法链 + 逐元素非线性」？如果没有非线性层，十层网络等价于什么？② 变式：如果每一层的权重都被限制为对角矩阵，这个网络的表达能力会退化成什么？③ 矩阵乘法在硬件上凭什么快（提示：和你熟悉的 CPU SIMD 有什么血缘关系）？

## 四、拷问题——代码任务通道（Q1–Q4）

代码要求：一律用 `.venv/bin/python` 跑通（numpy 已装），输出贴回作答稿；文件落 `代码/T2/`，文件头注释标对应题号与撞墙记录。挂靠项目见 [[02-项目驱动实践路线.md|项目路线]] Phase 2。

**Q1（挂项目 2.1，M2）**：**纯 Python 手写 matmul**。实现 `matmul(A, B)`：嵌套列表进嵌套列表出，形状不匹配时给出可读报错；与 numpy 随机矩阵对拍（误差 < 1e-9 断言）；再对 64×64 矩阵跑一次手写版 vs numpy 的耗时对比并贴结果——解释差距从何而来。

**Q2（挂项目 2.1，M3）**：**二维线性变换可视化**。定义「L」形点云（约 6 个点的坐标列表），分别施加旋转 90°、剪切、投影到 x 轴三个变换矩阵：打印变换前后坐标（可用简易 ASCII 网格）；并用断言验证「变换后的基向量 e1、e2 == 矩阵的两列」这一 M3 核心论断。

**Q3（挂项目 2.3，M5）**：**SVD 低秩近似**。用 numpy 构造一个合成矩阵（两个秩一矩阵相加再加小噪声），对它做 `np.linalg.svd`：① 打印奇异值谱（观察断崖）；② 用前 k（k=1,2,3,5）个奇异值重建矩阵，打印每个 k 的重建误差（Frobenius 范数）；③ 用一两句注释解释误差曲线为什么在 k=2 附近断崖。

**Q4（挂项目 2.4，M4）**：**手写 PCA**。生成带相关性的二维高斯点云（N≥500，用固定随机种子）：① 中心化 → 协方差矩阵 → `np.linalg.eigh` → 按特征值降序排好；② 投影到第一主成分，计算方差解释比并打印；③ 用 numpy 对中心化数据直接 SVD 交叉验证第一主成分方向（两法方向一致，允许符号相反）；④ 文件头注释写清「为什么第一主成分是最大特征值方向」的一句话直觉。
