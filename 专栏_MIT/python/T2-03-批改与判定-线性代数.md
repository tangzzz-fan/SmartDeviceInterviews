## 二、复攻记录（逐级提示，全部销账）

| 项 | 提示级别 | 复攻结果 |
|----|---------|---------|
| C1③ | 弱提示「只看一列」 | 学员写出硬例：旋转 R=[[0,-1],[1,0]] × 反射 S=[[1,0],[0,-1]]，R@S=[[0,1],[1,0]]、S@R=[[0,1],[-1,0]] 不同——「先转后翻 ≠ 先翻后转」落地。**变式**（A 可逆时 A@B=A@C⇒B=C；不可逆时不一定）答出 → 销账 |
| C2② | 中提示「[[1,0],[0,0]] 把平面压到哪」 | 接上 Q2 投影可视化的实感：压到 x 轴、y 坐标永久丢失 = 信息丢失；投影矩阵幂等+降秩补上。**变式**（det 是体积缩放因子、det=0↔奇异）答出 → 销账 |
| C3②③ | 中提示「max wᵀCw s.t. wᵀw=1，拉格朗日」 | 推导链补全：投影方差 = wᵀCw → ∇(wᵀCw−λ(wᵀw−1))=0 → Cw=λw → 最优方向即最大特征值方向，方差值即特征值；并用 Q4 实测（投影方差 3.4202 ≈ λ₁ 3.4259）锚定。③ 谱定理：实对称⇒特征值全实、不同特征值特征向量正交 → 销账。**变式**（量纲不同先标准化，否则大单位特征垄断第一主成分）答出 |
| C4 全部 | 中提示「秩一分量展开 A = Σ σᵢuᵢvᵢᵀ」 | 三问重建：Vᵀ 旋到正交基 → Σ 按 σ 逐轴拉伸 → U 旋到输出空间；奇异值排序本质是贪心取最大剩余能量；截断误差 = 丢弃奇异值平方和（正交分量互不干扰），丢最小损失最小。全部用 Q3 数字锚定（前二 15.9/13.8 vs 其余 ~0.08）→ 销账。**变式**（SVD 降噪 = 小奇异值方向承载噪声，截断即滤波）答出 |
| C5 | 首轮过关，**追加变式**（复习线条款：答得太顺） | (AB)ᵀ = BᵀAᵀ 用 (i,j) 元素定义推出顺序为何要反 → 维持过关 |
| C6②③ | 中提示「落到乘加+访存两点」 | ② 确认：对角阵之积仍对角 ⇒ 特征零交互，网络退化成逐特征仿射缩放；③ 落地两点：内积乘加密集可 SIMD/NEON/Tensor Core 向量化 + 连续访存可预取缓存友好 → 销账。**变式**（1×1 卷积 = 逐像素的通道线性组合）能接 |
| F1 | 弱提示 | 补边界：工程骨架打底、哪块直觉塌补哪块（本线的实际走法）→ 升过关 |
| F2 | 弱提示 | 补三条边界：变长序列/数据依赖控制流、稀疏结构、batch 太小时 kernel 启动开销占比高（激活本来就是 pointwise）→ 销账 |
| F3 | 中提示 | 补两条理由：显式构 C=XᵀX 把条件数平方（κ(C)=κ(X)²）数值更脆；N<D 时 C 是 D×D 巨阵而 thin SVD 便宜 → 销账 |
| Q2 | 弱提示 | 机制解释补上：任何向量是基的组合、线性变换保组合 ⇒ 基的去向唯一决定变换；断言从「会验」升为「会讲」→ 销账 |
| Q3 | 中提示 | 奇异值几何意义复述：σᵢ 是对应正交方向的拉伸倍数，谱断崖 = 信号秩数；Vᵀ 与 V 的区别用「Vt[:k] 的行就是前 k 个主方向」讲清 → 销账 |
| Q4 | 弱提示 | 文件头直觉句 + 复攻推导链口头复述一致；eigh 升序与 Vt 行方向两坑提炼成两条检查清单（「取特征向量前先确认排序」「方向在 Vt 行里」）→ 销账 |

**复攻结论：概念 8 项 + 代码 3 项全部销账；C5/C6① 首轮过关经受变式题检验维持原判。**
