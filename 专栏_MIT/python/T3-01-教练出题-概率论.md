## 一、共识模型（教练版五个骨架）

学员先自推五模型再对本版，标注差异。

| # | 模型 | 一句话骨架 |
|---|------|-----------|
| M1 | 随机变量是「结果→数字」的映射，分布是它的履历表 | 期望 = 长期平均（加权中心），方差 = 离散程度（偏差平方的期望）；二阶矩不是玄学，平方放大大偏差 |
| M2 | 贝叶斯 = 信念更新机 | 先验（事前信念）× 似然（证据的支持度）归一化 → 后验（事后信念）；P(A|B) ≠ P(B|A) 是万错之源 |
| M3 | 大数定律与 CLT | 样本均值随 N 增大钉死在真均值（LLN）；大量独立小随机叠加的分布趋近正态（CLT）；样本均值的标准差是 σ/√N |
| M4 | MLE：选让已见数据「最可能出现」的参数 | 似然 = 给定参数下数据的联合概率；取对数变连乘为连加；求导置零得估计 |
| M5 | softmax + 交叉熵是「分类的 MLE」打包好的样子 | softmax 把 logits 变成概率分布（指数放大差异 + 归一化）；类别分布 MLE 取负对数 = 交叉熵损失 |

## 二、争议焦点（三题，考有边界的立场）

- **F1**：频率派 vs 贝叶斯派——工程实践中「先验」什么时候真的有用、什么时候是负担？给出你站哪边与边界。
- **F2**：softmax 减最大值（log-sum-exp 技巧）是「工程卫生纪律」还是「数学必然」？不减会在哪里出事、减了为什么结果不变？
- **F3**：蒙特卡洛 vs 解析解——什么场景下你应该直接采样模拟而不是硬推积分/公式？给出判据。

## 三、拷问题——概念口述通道（C1–C6）

**C1（M2）**：疾病检测题：患病率 0.1%，检测灵敏度 99%（有病测出阳性），假阳性率 5%（没病测出阳性）。某人检测阳性，他真的患病的概率是多少？要求：① 算出数值；② 指出先验、似然、后验分别是谁；③ 解释为什么结果反直觉地低——「基率谬误」的直觉必须给。

**C2（M2）**：似然与概率的区别——L(θ|x) 和 P(x|θ) 写的是同一个式子，为什么一个叫似然一个叫概率？「固定什么、变化什么」说清楚；为什么似然不是 θ 的概率分布（不许只说「因为它不积分到 1」，要说出观点层的差别）。

**C3（M4）**：伯努利 MLE 现场推导：n 次独立试验观察到 k 次成功，写出似然函数 → 对数似然 → 对 p 求导置零 → 得出 p̂。每一步都要给，不许跳步直接写结论。

**C4（M5）**：推导链三连——① 分类任务里「标签的似然」怎么写（类别分布的联合概率）？② 取负对数后变成什么形式？③ 把模型输出用 softmax 参数化代入，为什么最终就是「交叉熵损失」？这条链是本轮核心，断一环按断链判。

**C5（M5）**：softmax 数值稳定性三连——① 不减最大值会在哪里出事（给出具体机制，不许只说「溢出」）？② 减去最大值为什么数学上结果不变？③ 全是很大的负数时不减会发生什么精度问题？

**C6（M3）**：① 样本均值的标准差为什么是 σ/√N？从方差的性质推（独立、方差可加、常数平方提出来）。② CLT 在 ML 里至少举两个真实出处（不许编，说不出 = 半）。

## 四、拷问题——代码任务通道（Q1–Q4）

代码要求：一律用 `.venv/bin/python` 跑通（numpy 已装），输出贴回作答稿；文件落 `代码/T3/`，文件头注释标对应题号与撞墙记录。挂靠项目见 [[02-项目驱动实践路线.md|项目路线]] Phase 3。

**Q1（挂项目 3.1，M3）**：**蒙特卡洛验证 LLN 与 CLT**。用 numpy 模拟：① 掷「不均匀骰子」（自定义分布）N=10…100000，画/打印样本均值随 N 收敛到真期望的过程（至少 5 个量级的采样点）；② 固定 N=30 重复 10000 次取样本均值，验证这堆均值的分布近似 N(μ, σ²/N)——用直方图统计量或分位数对比给证据，不许只打印「看起来像」。

**Q2（挂项目 3.2，M2/M4）**：**手写高斯朴素贝叶斯分类器**。自己生成两团带不同均值/方差的二维高斯数据（固定种子、含训练/测试划分）：先验按训练集频率估计，似然用每维独立高斯（说出「朴素」假设了什么），预测用后验比较。报告测试集准确率；**必须用对数概率计算**，并在文件头解释为什么不能直接连乘概率。

**Q3（挂项目 3.3，M5）**：**softmax 数值稳定性实验**。写 naive 版与减最大值版两个 softmax：① 构造 float32 下会让 naive 版出 inf/nan 的 logits（打印证据），减最大值版安然无恙；② 在正常数值范围内证明两版输出一致（误差断言）；③ 顺手实现 log_softmax 并解释为什么「先 softmax 再取 log」是坏主意。

**Q4（挂项目 3.4，M4/M5）**：**MLE 与交叉熵从零实现**。① 生成 n=1000 次伯努利试验数据，手写对数似然函数，用网格搜索（或求导公式）找最大化它的 p̂，与样本频率对比（应一致到小数点后两位）；② 手写类别分布交叉熵 `ce(logits, labels)`（含减最大值稳定化），造一组 logits/labels 验证：正确类 logit 越大损失越小、损失非负、均匀 logits 时损失 = log(类别数)。
