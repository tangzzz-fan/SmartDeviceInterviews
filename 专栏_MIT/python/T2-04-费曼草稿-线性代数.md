## 一、五模型重推（脱稿版）

**M1 向量的双重身份**：向量既是一条数据样本（一行），也是一个有方向有长度的几何箭头。维度不神秘——就是特征个数。我以前的误区是只把它当数组。

**M2 矩阵乘法三副眼镜**：① 元素怎么来的——行×列内积；② 结果长什么样——C 的每一列是 A 的各列按 B 对应列的分量加权组合（所以 C 的第 j 列只由 B 的第 j 列决定）；③ 对输入干了什么——B 先把向量搬一次，A 再搬一次。交换律不成立是因为「先转后翻 ≠ 先翻后转」：旋转 R=[[0,-1],[1,0]] 配反射 S=[[1,0],[0,-1]]，两种顺序乘出来不一样。

**M3 矩阵=线性变换，列是基的去向**：A@(1,0)ᵀ 算出来就是 A 第一列——因为任何向量都是基向量的组合，线性变换保组合，所以只要知道 e1、e2 被送到哪，整个平面的命运就定了。奇异矩阵就是把平面压扁（比如压到一条线）：y 坐标永久丢失，所以不可逆 = 信息找不回来。Q2 里投影把 L 压成 x 轴一行，就是亲眼看到的版本。

**M4 特征分解与 PCA**：特征向量是「变换后不被转向、只被拉伸」的方向，特征值是拉伸倍数。PCA 的推导链我这次亲手走通了：投影到方向 w 的方差 = wᵀCw，在 ||w||=1 下最大化，拉格朗日求导得 Cw = λw——最优方向就是最大特征值的特征向量，方差值就是特征值本身（Q4 实测投影方差 3.4202 ≈ λ₁ 3.4259）。协方差矩阵对称，所以特征值全实、特征向量正交（谱定理）。

**M5 SVD = 旋转×拉伸×再旋转**：A = UΣVᵀ：Vᵀ 把输入旋到一组正交基，Σ 沿每个轴按奇异值拉伸，U 再旋到输出空间。奇异值按「剩余能量最大的方向」贪心排队，所以天然降序。截断前 k 个之所以是最优近似：各方向正交独立，重建误差的平方和恰好等于被丢弃奇异值的平方和——想损失最小就丢最小的。Q3 里秩二矩阵的奇异值谱 15.9/13.8 之后断崖到 0.088，k=2 收完信号、再收的全是噪声。

## 二、Swift/iOS 对照小节

- **矩阵 = 函数**：矩阵对向量的作用就像 `(CGPoint) -> CGPoint` 的纯函数；CGAffineTransform 的构造方式（a,b,c,d,tx,ty）本质上就是「前两列 = 基向量去哪 + 平移」——我用了多年的 transform 原来就是 M3。
- **形状检查 = 类型系统**：(N,D)@(D,K) 的内维相消，像泛型约束 `where A.Output == B.Input`——编译器替你查的事，numpy 用运行时报错查。
- **GEMM 快 = Accelerate/NEON 快**：手写 matmul 慢 394 倍的原因，和我当年不用 simd_float 手写向量运算慢是同一个故事——乘加密集 + 访存规整，硬件一条指令吃多个乘加。
- **eigh 升序坑 = API 排序约定坑**：和 Swift 里 `sorted(by:)` 不指定就默认升序一样，数学 API 的排序约定不看文档就会翻车；我提炼了两条检查清单（取特征向量先确认排序；数据方向在 Vt 的行里）。

## 三、给 iOS 同事讲懂（自检段落，T2 强制）

模拟对象：只会 UIKit/Swift、没碰过机器学习的同事。

> 「你做过 UIView 的 transform 动画吧？那个 CGAffineTransform 就是个 2×3 矩阵——它的前两列告诉你 x 轴单位向量和 y 轴单位向量动画后去了哪，整个视图的命运由这两个箭头决定。神经网络每一层干的就是同一件事：权重矩阵 W 把一批数据向量 (N,D) 搬进新空间 (N,K)，偏置是平移，激活函数是每个点单独的非线性扭曲。为什么全是矩阵乘法？因为它是『每个输出都是所有输入的加权组合』——特征之间充分混合信息，而且这种规整的乘加循环 GPU 一条指令算一片，快得离谱。PCA 就是找数据被拉得最长的方向；SVD 就是把任何变换拆成『转一下、拉伸、再转回来』，拉伸倍数按大到小排，压缩图片就是把小倍数扔掉。」

自检结果：transform 类比同事一定秒懂「列=基去向」；「为什么全用矩阵乘法」落到混合信息+硬件快两点，没有黑话；PCA/SVD 一句话版没掉进公式。卡壳过一次：解释「奇异矩阵信息丢失」时我先说了行列式——同事不懂行列式，改口用「投影把 y 坐标永久弄丢」才讲通。**教训：给外行讲，先丢概念后举例，顺序反了就是自嗨。**

## 四、60 秒讲稿（电梯版）

矩阵就是变换：列写着基向量去哪，乘向量就是搬点。神经网络每层是「搬一次 + 每个点扭一下」，搬的部分全靠矩阵乘法，因为它让所有特征充分混合且硬件算得飞快。PCA 找数据最长的方向——那是投影后方差最大的方向，数学上就是协方差矩阵的最大特征值方向。SVD 把任何变换拆成旋转×拉伸×旋转，拉伸倍数按重要性排好队，扔掉小队列就是最优压缩。
