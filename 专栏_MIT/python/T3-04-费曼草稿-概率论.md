## 一、五模型重推（脱稿版）

**M1 随机变量与分布**：随机变量把随机结果翻译成数字，分布是它的完整履历。期望 = 长期平均（加权中心）；方差 = 偏差平方的期望——平方不是随手选的，它放大大偏差、保住正负不抵消，这就是「二阶矩」的意义。

**M2 贝叶斯 = 信念更新机**：先验（事前信念）× 似然（证据在两种世界下的出现率）→ 归一化 → 后验。疾病检测题的教训：证据再强（灵敏度 99%）也架不住基数悬殊——1000 人里真阳性约 1 个、假阳性约 50 个，后验只有 1.9%。P(A|B) ≠ P(B|A)，混淆这两个是统计误用的万恶之源。再测一次阳性，1.9% 变新先验，后验抬到约 27%——信念是可以连续更新的。

**M3 LLN 与 CLT**：样本越多，均值越钉死在真值（LLN）；而「样本均值这个统计量本身」的分布，随 N 增大趋近正态，标准差是 σ/√N——推导：独立方差可加得 Nσ²，除以 N 时方差除 N²（常数进方差要平方）。ML 出处：mini-batch 梯度噪声 ∝ 1/√B（batch 翻倍只降 √2 倍，收益递减的根源）、权重初始化的方差设计。

**M4 MLE**：参数估计的朴素哲学——选那个让已见数据「最可能出现」的参数。伯努利推导链我这次走熟了：似然 p^k(1−p)^(n−k) → 取对数变加法 → 求导置零 → p̂ = k/n。取对数还有个工程理由：连乘会下溢（Q2 实测 400 维归零），连加永不。

**M5 softmax + 交叉熵 = 分类的 MLE 打包**：本轮最大增量。链条三环：① 分类似然 = 每个样本真实类概率的连乘 ∏ p_{yᵢ}；② 取负对数变求和，最大化似然 = 最小化 NLL；③ 用 softmax 参数化代入，−log p_y = −z_y + log Σ exp(z)——这就是交叉熵。所以训练分类模型就是在做 MLE，损失不是拍脑袋选的。softmax 减最大值：数学上免费（e^{−c} 公因子上下约掉），工程上必须（float32 上界 3.4e38，exp(100) 直接爆）。

## 二、Swift/iOS 对照小节

- **贝叶斯更新 = 增量式状态估计**：像 CoreLocation 融合多传感器——先验是上一帧位置，新观测是似然，滤波后输出是后验；每次 GPS 刷新就是一轮贝叶斯更新。
- **对数域计算 = 防溢出的工程纪律**：和音频/动画里用分贝（log 域）处理大动态范围一个道理——乘法变加法，动态范围压缩，比较大小不变。
- **性质断言 = XCTest 用例设计**：Q4 抓住符号错的不是公式复查，是「损失必须非负、必须单调、均匀时必须 = log K」三条性质护栏——和好测试用例的判据一模一样：测性质，不测实现。
- **蒙特卡洛 = 用模拟当 oracle**：刷题时验证概率题的标配手法，现在有了名字和判据（解析不可得/高维/只需数值/可重复采样时优先）。

## 三、给 iOS 同事讲懂（自检段落，T3 强制）

模拟对象：只会 UIKit/Swift、没碰过 ML 的同事。

> 「你们做过 A/B 测试吧？『看到数据后该多相信哪个版本』就是贝叶斯在干的事：先有个初始相信程度（先验），新数据进来（证据），更新后的相信程度叫后验。有个反直觉的坑：罕见病检测阳性，真患病概率可能才 2%——因为没病的人太多，假阳性的绝对人数碾压真阳性。再说模型训练：分类模型的损失函数『交叉熵』不是随便挑的——它就是『让训练数据出现的概率最大』这个朴素目标（最大似然）套上 softmax 之后的数学化身。为什么 softmax 要先减最大值再 exp？float32 最大才 3.4e38，exp(100) 直接爆掉；减去最大值结果不变——分子分母同乘的常数约掉了，免费的保险。」

自检结果：A/B 测试的锚点同事秒懂；疾病题用「数人头」讲不讲公式也对；交叉熵来历讲到「朴素目标的数学化身」没掉进推导。卡壳过一次：解释「似然不是概率」时我先甩了「不归一」——同事完全没接住，改口「概率是给定模型猜数据，似然是给定数据猜模型」才通。**教训复用（同 T2）：观点先于形式，类比先于公式。**

## 四、60 秒讲稿（电梯版）

贝叶斯是信念更新机：先验乘上证据的支持度，归一化成后验——证据再强也要掂量基数。样本越多均值越准，而且样本均值的分布总是趋近正态，宽度按 1/√N 收窄。训练模型本质是最大似然：选让数据最可能出现的参数；分类任务把这个目标套上 softmax，得到的就是交叉熵——所以损失函数不是玄学。工程上两个免费保险：连乘改连加防下溢，softmax 减最大值防溢出。

## 五、本轮学习复盘

首轮 C4 整链未过是本轮最狠的判定——「交叉熵是分类损失」我用了多年却从没接上过 MLE 的源头，复攻补全三环再回看 Q4 的均匀 logits = log K，才真正理解那是「模型毫无信息时的 NLL」。三个方法论收获：① **性质断言兜底符号错**（Q4 漏负号被非负断言当场抓住）——T4 梯度对拍沿用；② **数值量级要算不要猜**（下溢阈值错一个数量级被实测打脸）；③ **对照组要选会犯病的版本**（Q3 坏写法演示配错对）——这三条都是可迁移的工程纪律，不只是数学。
