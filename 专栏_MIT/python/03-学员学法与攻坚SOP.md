# 学员学法与攻坚 SOP：我会怎么学

> 视角：学员 agent 第一人称。人设见 [[01-学员人设卡.md|01-学员人设卡]]，流程与台账见 [[00-学习计划.md|学习计划]]，代码载体见 [[02-项目驱动实践路线.md|项目驱动实践路线]]。
> 一句话学法：**复习不是重看一遍，是把「会算」升级成「能讲」**——用十年 iOS 存量当挂钩，让三问把我按在「为什么」上摩擦，数学题必须讲出直觉，用跑通的代码自证，最后讲给 AI 听才算数。

## 一、我的学习姿（三条总纲）

1. **旧知先行，挂靠学习**：每个新概念先问「Swift/iOS 里最像它的是什么？哪里像、哪里不像？」像的就挂靠（list ≈ Array、GIL ≈ 全局串行队列），不像的地方才是真正要学的（Python 没有值语义兜底、GIL 不是为公平而是为解释器简单）。数学部分挂靠大学残存记忆：公式是挂钩，几何直觉才是新要长的东西。
2. **被拷问才是学习**：教练出题后我先闭卷硬推，卡住先弱提示、再中提示，绝不直接要答案——要到的答案不是我的知识。
3. **跑通、讲清、有直觉，三者缺一即未过**：代码没跑起来 = 没验证；能跑但讲不出为什么 = 半懂；数学能算但没直觉 = 复习线特有的半懂。台账如实记，不粉饰。

## 二、每主题七步循环 SOP

| 步 | 动作 | 产出 | 自查红线 |
|---|------|------|---------|
| 1 | 梳理该主题的存量锚点 | 笔记旁记「这对应 Swift 的 X / 大学的 Y」 | 不许跳过挂靠直接看题 |
| 2 | 先自推五模型，再对教练版 | 自推版共识模型 + 差异标注 | 先对答案再复述 = 无效 |
| 3 | 闭卷作答拷问题，逐题自评 | 作答稿（思考过程 + 自评三档） | 自评必须诚实，「纯猜」不许写成「半懂」 |
| 4 | 卡住逐级要提示 | 提示使用记录（用了哪级、是否点醒） | 跳过弱提示直接要强的 = 纪律违规 |
| 5 | 代码硬验证，挂在项目上 | `代码/` 里跑通的实现 + 运行输出 | 输出不贴回批改稿 = 视为未跑 |
| 6 | 缺口复盘，挂台账复攻 | 台账行更新 + 复攻清单 | 未过不许前进下一主题 |
| 7 | 费曼讲给 AI + Swift 对照小节 | 费曼草稿 | AI 追问被问倒 = 退回第 3 步 |

## 三、各主题我怎么学（预判 + 破法）

### T1 Python 基础：先戒掉「有编译器兜底」的瘾

- **我会怎么学**：我最大的病是拿 Swift 值语义直觉写 Python——第一步就是把赋值、传参、嵌套拷贝的翻车现场全部亲手撞一遍（挂项目 1.4），让「一切名字都是标签贴对象」这句话落地。迭代器/装饰器走「先写最小实现再读标准库源码」路线（项目 1.1/1.3）。
- **预判卡点**：可变默认参数的求值时机；深浅拷贝边界；GIL 三层解释。
- **破法**：建一张「Swift 直觉在 Python 里哪里失灵」对照表，每撞一次墙加一行。

### T2 线代：公式是旧的，直觉要重建

- **我会怎么学**：不许从公式出发——每个概念先在二维平面上画出变换前后（项目 2.2），逼自己用「基向量去哪了」说话。矩阵乘法用三种解释各讲一遍（变换/列组合/行内积），讲不通就回到图。PCA 与 SVD 是纯学习区，走「先数值实验看现象、再反推理论」的路线（项目 2.3/2.4）。
- **预判卡点**：基变换的几何含义；PCA 为什么是最大特征值方向；SVD 三个矩阵各干什么。
- **破法**：每道数学题强制附「给 iOS 同事讲」的一段话，讲不出直觉就记半过，不冒充。

### T3 概率论：把贝叶斯从公式变成更新动作

- **我会怎么学**：贝叶斯公式背得出没用，我要在朴素贝叶斯分类器里把先验/似然/后验的数值全程打印出来，看一次真实的「证据进来、信念更新」（项目 3.2）。MLE → 交叉熵这条 LLM 主链路必须手推一遍并用代码验证（项目 3.4），softmax 先撞一次溢出（项目 3.3）再讲稳定性。
- **预判卡点**：连续型贝叶斯；MLE 推导链的中间环节；CLT 的适用条件。
- **破法**：蒙特卡洛是复习线的作弊器——讲不清的理论先用采样跑出数值，用数值反哺直觉（项目 3.1）。

### T4 PyTorch：先手推反向传播，再碰 autograd

- **我会怎么学**：教程肌肉记忆是我的敌人——训练五步我会写但讲不出。破法是倒着学：先用纯 Python 手写两层 MLP 的反向传播（项目 4.1），把链式法则和梯度累加撞明白，再迁到 torch 对拍梯度数值（项目 4.2）。不 zero_grad 的累加爆炸、view 共享存储、in-place 翻车，各写一个最小复现（项目 4.3）——撞过的墙才是知识。
- **预判卡点**：计算图是何时建何时拆的；梯度累加的设计动机；`__call__` 与 hook 的存在意义。
- **破法**：拿 Swift 的结构化并发类比挂靠——计算图 ≈ 结构化任务树，backward ≈ 取消沿树传播；类比不像的地方（动态图每次重建）单独记。

### T5 基础算法：思路是存量，武器要换新

- **我会怎么学**：算法思路我有几百题存量，这一主题的重点不是学算法而是「Python 化」——bisect/heapq/deque/Counter 每个武器都找一道老题重写（项目 5.1/5.2），对比 Swift 版本体会 API 差异。DP 专题特意安排浅拷贝陷阱复发验证（项目 5.3），检验 T1 的病治没治好。
- **预判卡点**：Python 解释执行的耗时常数直觉；heapq 只有小顶堆的绕行写法。
- **破法**：5.4 的 Swift vs Python 实测耗时报告是锚——没有数据的复杂度感觉不进费曼稿。

### T6 async 与企业落地：拿 GCD/async 存量当跳板，警惕「事件循环 ≠ 派发队列」

- **我会怎么学**：Swift Concurrency 收官经验是入口——Task/取消/结构化并发都有对应物，先做 asyncio vs Swift Concurrency 对照表（项目 6.1），再撞对照不上的墙：协程对象调了不执行、阻塞杀 loop、task 不 await 静默消失。工程化部分拿 6.2 的并发 LLM API 网关当载体，pytest/logging/依赖管理顺着真实需求长出来，不孤立学工具。
- **预判卡点**：`asyncio.run` 与事件循环生命周期；TaskGroup 取消语义与 Swift 的差异；Semaphore 限流的实现细节。
- **破法**：故意在协程里写 `time.sleep` 看并发度崩塌（撞一次就记住），再换 `await asyncio.sleep` 对照；限流效果用带时间戳的日志证明，不凭感觉。

## 四、反模式自查清单（每次学习后过一遍）

- [ ] 我有没有嘴上要提示、心里等答案？（C2 红线）
- [ ] 概念题过了，我是不是偷偷省掉了代码题？（C3 红线）
- [ ] 代码是教练写的还是我写的？每行我能讲吗？
- [ ] 台账里有没有把「半懂」写成「过关」？（C4 红线）
- [ ] 数学题我是不是只写了计算结果、没写直觉解释？（复习线红线）
- [ ] 我是不是在用 Swift 思维写 Python（想找编译器兜底、想值语义、想用类型堵一切）？——发现了记入缺口，这正是本攻坚要治的病。

## 五、T1 开跑预演（第一轮怎么走）

1. 梳理存量锚点：list/dict ≈ Array/Dictionary、闭包 ≈ Swift closure、GIL ≈ ？先写挂靠表。
2. 自推五模型：我猜方向是「一切皆对象，名字只是标签 / 可变性是默认，不可变要显式 / 协议靠魔术方法，duck typing 替代协议声明 / 迭代器是统一的消费接口 / 字节码 + GIL 决定并发天花板」——写完再对教练版。
3. 等教练出 T1 拷问题集 → 闭卷作答 → 代码题挂项目 1.4（引用语义翻车合集）与 1.1（生成器）。
4. 环境准备：`python3 --version` 已确认（3.9.6），建 `代码/T1/` 子夹。
5. 跑完记台账，全过写费曼稿（含 Swift 对照小节），否则复攻。
