## 二、复攻记录（逐级提示，全部销账）

| 项 | 提示级别 | 复攻结果 |
|----|---------|---------|
| C1 | 弱提示「显存装不下大 batch 怎么训」 | 两类用途钉死：梯度累积（micro-batch 攒够再 step，loss 取平均时数学等价大 batch——线性性）、多任务多 loss 分别反传；引擎视角补全：autograd 无法预知调用次数，覆盖语义会悄悄破坏合法用法，累加是线性安全的默认。**变式**（等价性证明：N 个 micro-batch 平均梯度的平均 = 全 batch 平均）答出 → 销账 |
| C2 | 中提示「print model._parameters 和 _modules」→ 强提示「__setattr__ 拦截」 | 机制补全：__setattr__ 拦截赋值，Parameter→_parameters、Module→_modules，parameters() 递归两字典；普通 tensor 属性不被收集（实验：赋值后 print _parameters 为空）。**变式**（register_buffer：参与 forward 但要梯度、不进优化器、随 state_dict 保存）答出 → 销账 |
| C3 | 中提示「打印 loss.grad_fn 看链」 | 三环补全：①逆拓扑序遍历，每节点用保存的中间量算局部导数链式相乘，叶节点累加进 .grad；②节点是张量挂 grad_fn，函数执行完就没了、图是运行时对象；③首次 backward 默认释放非叶缓冲区，retain_graph=True 才保留。**变式**（retain_graph 的真实场景：GAN 双反传、多 loss 分开反传）答出 → 销账 |
| C4 | 弱提示「data_ptr 相等说明什么」 | 正交两维钉死：**存储维度**（view 共享/clone 拷贝）× **图维度**（view/detach 前的链在图里/detach 切断）；CoW 错在「写时复制」——torch 无拷贝写穿透。**变式**（reshape 不连续时内部 copy，不保证共享）答出 → 销账 |
| C5 | 直接引用 Q3 四墙经验 | 三连补全：①version counter——宁可炸不拿污染数算错梯度；②optimizer 的 in-place 发生在图释放后、走 .data 绕版本追踪；③存 loss 张量做统计会让图无法释放、显存随步数泄漏，item() 是纪律。**变式**（非 in-place 的 add 为什么没事：新张量新节点，旧保存量不受影响）答出 → 销账 |
| C6 | 弱提示「每一步在修 grad 还是 param」 | 四问固化：①累加→等效 lr 线性膨胀；②None 报错→陈旧梯度；③滞后一步；④优化目标被篡改为激活统计。**变式**（推理时 no_grad+eval 三件事全免：不建图省显存、关训练态）答出 → 销账 |
| F1 | 弱提示 | 补全代价层：图级优化（算子融合/内存规划/自动并行）动态图做不了；收敛论证：torch.compile 就是把动态图 trace 成静态图再优化——两条路线在部署/编译端合流 → 销账 |
| F2 | 弱提示 | 所有权框架固化：view = 借出引用（只读/形状变换），clone/detach = 交接所有权（独立写入/带出训练上下文/防梯度意外回流）——与 Swift 的 buffer 所有权心智对接成功 → 销账 |
| F3 | 弱提示 | 默认值之争补完：step 后自动清零会让攒梯度被迫换写法（手动保存/恢复），现状是把选择权留给调用方；真实场景补 MAML 类元学习（内外环梯度叠加依赖累加语义）→ 销账 |
| Q1 | 复攻口述（代码已自清） | ReLU 门断环复盘：链式法则「显然的一环」恰是断环高发区；数值对拍的定位能力验证——W1/b1 错而 W2/b2 对，误差分布直接指出断点在 W2 下游 → 销账 |
| Q2 | 复攻口述 | weight 存 (out, in) 的原因讲清：F.linear 走 BLAS 习惯 y = xWᵀ+b，行存权重对按行取输出友好；dtype 纪律：跨框架转换显式声明精度，对拍场景统一 float64 → 销账 |
| Q3 | 复攻口述 | 「哪个 op 保存了哪个张量」决定炸点——报错信息里 output 0 of Add/Relu 就是线索；detect_anomaly 可定位肇事 op → 销账 |
| Q4 | 复攻口述 | 「平均的平均」纪律固化：先写每份的分子分母再合并；备选严格判据：drop_last 保证 batch 等长后简单平均才合法 → 销账 |

**复攻结论：概念 9 项 + 代码 4 项全部销账；人设卡 T4 四条预期漏洞全部命中、全部修复留痕。**
