# T8-01 教练密卷：Embedding 与向量检索（仅教练分支，学员禁阅）

> 本文件含弱/中/强三级提示、评分要点与参考答案。使用纪律：直接要答案 → 反问「你的测试集和指标是什么」。

## 一、概念题：提示梯与评分要点

### C1 余弦 vs 欧氏
- 弱提示：余弦归一化了吗？两个向量长度不同但方向相同，相似吗？
- 中提示：embedding 常用归一化；归一化后余弦与欧氏是什么关系？
- 强提示：归一化后余弦排序 ≈ 欧氏排序（单调相关），但余弦对「方向」语义更直观；「猫 vs feline」这类同义不同形靠 embedding 训练语料拉近。
- 评分要点：真懂特征：归一化关系 + 语义坐标直觉 + 例子。
- 参考答案：归一化后两者排序一致；余弦表达方向语义；同义近义由训练语料决定。

### C2 切分边界效应
- 弱提示：一个 50 词的段落被固定窗口切成两半，中间那 10 个词（事实主语）会怎样？
- 中提示：重叠窗口能缓解「切断」吗？按段落切分会不会把「过长段落」整个截掉？
- 强提示：固定+重叠：边界平滑但可能切断语义单位；按段落：语义完整但粒度粗、长段落超预算。事实被切 = 召回时上下文缺主语，答案会编。
- 评分要点：真懂特征：两种策略的边界效应 + 事实切断后果。
- 参考答案：固定+重叠保粒度丢语义完整性；按段落保语义丢粒度；两者都要考虑 max_chunk_tokens 与「事实完整性」优先。

### C3 精确 vs ANN
- 弱提示：全量扫描的复杂度是多少？10 万条 × 1536 维呢？
- 中提示：faiss 用索引（IVF/HNSW）换速度，代价是什么（召回率、内存、构建时间）？
- 强提示：规模门槛（万级 numpy 可撑，百万级必须 ANN）；ANN 牺牲召回率换延迟；业务影响 = 漏检率，可接受与否看评估。
- 评分要点：真懂特征：规模门槛 + 权衡维度 + 用评估说话。
- 参考答案：万级全量可跑；百万级上 ANN；近似漏检用 hit@k 评估是否可接受。

### C4 RAG 管道失败模式
- 弱提示：把管道拆成五环，每一环「什么情况下产出是坏的」？
- 中提示：切分切断事实 / embedding 对术语不敏感 / top-k 漏检 / 上下文超长被截 / 组装顺序乱——哪一环最常先坏？
- 强提示：定位方法 = 每环单独验证：切分看 chunk 内容、召回看 hit@k、组装看上下文完整性；先测召回再谈答案。
- 评分要点：真懂特征：五环失败模式 + 逐环定位方法。
- 参考答案：五环各有失败模式；定位从「召回质量」先查（hit@k），再查切分与组装。

### C5 hit@k / MRR
- 弱提示：hit@k 回答「正确答案在不在前 k 里」；MRR 回答「排在第几位」。
- 中提示：MRR = 1/rank 的平均；hit@1 是 rank=1 的命中率。
- 强提示：hit@k 是召回率视角，MRR 是排序质量视角；评估必须有测试集 + 指标 + 对照策略。
- 评分要点：真懂特征：两个指标定义 + 各自回答的问题。
- 参考答案：hit@k = 正确答案出现在前 k 的比例；MRR = 平均 1/rank；hit@1 衡量首条准不准，MRR 衡量排序。

### C6 embedding API vs 本地
- 弱提示：API embedding 的维度/成本/延迟 vs 本地模型（如 sentence-transformers）的运维/质量？
- 中提示：企业内部文档的「术语密度高、数据敏感」两个特征分别指向哪边？
- 强提示：数据敏感 → 本地优先；术语密度高 → 需要领域微调或高质量通用模型；维度高不一定质量高。选择 = 质量 / 成本 / 隐私 / 延迟四维权衡。
- 评分要点：真懂特征：四维权衡 + 场景判断。
- 参考答案：敏感数据本地、术语密集需评估领域适配、维度与质量非正比；选择按质量/成本/隐私/延迟四维记账。

## 二、争议焦点参考立场

- F1：默认固定大小 + 重叠起步，术语/事实完整性敏感再上语义切分；站死一方 = 半过。
- F2：万级 numpy 精确可跑；百万级上 ANN；升级前先用 hit@k 量化召回损失。
- F3：RAG 是当前性价比默认（可解释、可更新）；微调解决「格式/风格」、超长上下文解决「单文档」；按场景选。

## 三、代码题：评分要点与提示

### Q1 余弦 + top-k
- 评分要点：mock embedding 确定性；余弦矩阵正确；query top-k 排序符合直觉；输出贴回。
- 参考答案要点：`cos = X @ q / (||X||*||q||)`；`np.argsort` 取 top-k。

### Q2 切分器
- 评分要点：两版都实现；chunk 边界打印；至少指出一处「事实被切断」实例。
- 参考答案要点：固定窗口 word 级滑动 + 重叠 overlap；按段落按空行/句号切。

### Q3 迷你 RAG
- 评分要点：管道五环完整；两种切分各跑一遍；上下文组装含顺序 + token 预算截断；比较结论。
- 参考答案要点：`pipeline(doc, query, chunker)` 返回组装上下文；打印两种 chunker 的召回差异。

### Q4 召回评估
- 评分要点：10 查询测试集标注；hit@1/hit@5/MRR 实现正确；两策略指标对比 + 结论。
- 参考答案要点：`hit@k = mean(any(gold in topk))`；`MRR = mean(1/rank)`；结论要有数字。

## 四、使用纪律

- 判分只认证据：指标数字、切分边界实例、管道输出都要留档；「感觉更好」不算。
- 失真自查：没有测试集就下结论、指标算错、管道缺环 = 该题作废重跑。
