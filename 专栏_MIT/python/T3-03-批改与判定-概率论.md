## 二、复攻记录（逐级提示，全部销账）

| 项 | 提示级别 | 复攻结果 |
|----|---------|---------|
| C1 | 弱提示「1000 个人摊开数人头」 | 角色指派钉死：先验=患病率、似然=两个条件概率（P(阳\|病) 与 P(阳\|无病) 都算证据模型）、后验=P(病\|阳)；基率直觉落地为「1/1000 vs 50/1000」。**变式**（再测一次阳性，1.9% 作新先验 → ≈27%）答出，「两次独立证据抬信念」讲清 → 销账 |
| C2 | 中提示「归一化常数依赖 x」 | 补出观点层：概率是「模型→数据」的生成视角，似然是「数据→模型」的追责视角；频率派 θ 非随机变量，似然对 θ 不归一。**变式**（MAP = MLE × 先验，「带正则的 MLE」）答出 → 销账 |
| C3 | 弱提示（链已走通，只练熟） | 脱稿重推一遍，求导符号不再犹豫。**变式**（ln 单调不改 argmax；连乘下溢与 Q2 实测互证）答出 → 销账 |
| C4 | 中提示「独立样本联合概率连乘」→ 强提示「softmax 代入逐项展开」 | 三环补全：①似然 = ∏ᵢ p_{yᵢ}（模型给真实类的概率连乘）；②−ln∏ = Σ−ln p_{yᵢ}（最大化似然=最小化 NLL）；③代入 softmax 得 −z_y + log Σⱼexp(zⱼ)，正是交叉熵。用 Q4 实测锚定：均匀 logits CE = log 5 = 模型毫无信息时的 NLL。**变式**（标签平滑动了真值分布那一环）能接 → 销账 |
| C5 | 弱提示「分子分母提公因子」 | ②不变性补出 e^{−c} 上下约掉的完整式；③负数区机制钉死：exp 集体下溢到 0 → 0/0 = nan，Q3 的 [nan nan nan] 输出就是实锤 → 销账 |
| C6 | 弱提示「Var(aX)=a²Var(X)」 | ①推导固化：Var(Σxᵢ)=Nσ²（独立可加）→ Var(X̄)=Nσ²/N²=σ²/N；②补第二个硬出处：权重初始化（Xavier/He 的方差设计）与评估指标置信区间 → 销账。**变式**（batch 翻倍噪声只降 √2 倍——收益递减根源）答出 |
| F1 | 弱提示 | LLM 场景落地补一例：语言模型输出的校准/温度缩放可视为对先验置信度的工程干预；负担面补「先验选错的偏差不可随数据完全洗掉」→ 销账 |
| F2 | 弱提示 | 两面论证补完整：不变性是代数恒等（免费），必要性是 float32 上界 3.4e38 决定的（必须）——结论「数学上免费、工程上必须」从直觉升为论证 → 销账 |
| F3 | 首轮过关，**追加变式**（复习线条款：答得太顺） | 「什么时候采样是错的」：需要严格可导/精确界（理论证明）、低维有闭式解、采样成本高于推导——答出 → 维持过关 |
| Q2 | 直接要求（题干硬指标） | 对数域版落地：log 后验 = log 先验 + Σ log 密度，log-sum-exp 归一，准确率 0.992 不变；下溢阈值修正为「~700 个 0.01 或 ~220 个 1e-3 才到 float64 底」并写进文件头 → 销账 |
| Q3 | 弱提示 | 坏写法的「病灶定位」讲清：稳定版减最大值后最大项恒为 exp(0)=1，永不犯病；病只在 naive 版 + 大负数区——对照组必须选会犯病的版本 → 销账 |
| Q4 | 中提示「CE = −(z_y − log Σexp(z))」 | 符号纪律 + 推导打通：−log p_y 的负号来自 NLL 定义（C4 链条的代码化身）；性质断言方法论总结为「非负、单调、均匀=log K 三条护栏」→ 销账 |

**复攻结论：概念 8 项 + 代码 3 项全部销账；F3 首轮过关经受变式题检验维持原判。**
