# T2-01 教练密卷：线性代数（仅教练分支，学员禁阅）

> 配套题干：`T2-01-教练出题-线性代数.md`。本文件含判分点、弱/中/强三级提示、复习线变式题、失真自查清单。
> 复习线判定基准：**会算但无直觉 = 半过**；带「背公式不推理」味 = 半过；答得太顺 → 追加变式题，答不出降档。

## 一、概念题判分点与提示梯

### C1 矩阵乘法三重解释
- **判分点**：① 三副眼镜都要到：行内积（C[i][j] = A 第 i 行·B 第 j 列）、列组合（C 的第 j 列 = A 的各列以 B 第 j 列分量为权重的线性组合，C = A@B 即「A 的列空间里重新摆点」）、线性变换（B 先把输入搬一次，A 再搬一次，复合变换）；② C[:,j] = A @ B[:,j]，所以只由 B 的第 j 列决定；③ 反例需是同尺寸可交换次序的 2×2，如旋转 90° R=[[0,-1],[1,0]] 与 x 轴反射 S=[[1,0],[0,-1]]：R@S 与 S@R 结果不同（几何上「先转后翻」≠「先翻后转」）。
- **弱提示**：C 的第 j 列到底由 A 的什么和 B 的什么算出来？只看一列试试。
- **中提示**：列组合视角——A@v 是 A 的列的线性组合，权重是 v 的分量。
- **强提示**：C[:,j] = A @ B[:,j]；反例用「旋转+反射」或「旋转+剪切」，两个都写出来乘一遍。
- **复习线变式**：若 A 可逆且 A@B = A@C，B=C 吗？A 不可逆时呢？（可逆：两边左乘 A⁻¹ 即得；不可逆：不一定，奇异矩阵把不同输入压到同一处。）

### C2 矩阵=变换，列是基向量去向
- **判分点**：① A@e_j 恰好取出 A 的第 j 列（e_j 只有一个 1），所以「列 = 基向量的落点」；整个变换由基向量去向唯一确定（线性性）；② 奇异矩阵把平面压到低维（直线/原点）——秩亏 = 像空间维度下降；不可逆 = 压缩后无法还原 = 信息丢失；投影矩阵是典型的幂等+降秩。
- **弱提示**：把 (1,0) 和 (0,1) 分别乘进矩阵，看结果等于什么。
- **中提示**：任何向量 = 基向量的线性组合，线性变换保持组合关系，所以基向量的去向决定一切。
- **强提示**：A@(1,0)ᵀ = A 的第 1 列（按定义乘一遍）；奇异矩阵例 [[1,0],[0,0]] 把平面压到 x 轴。
- **复习线变式**：行列式的几何意义是什么？det=0 和奇异是什么关系？（体积缩放因子；det=0 ↔ 压扁到低维 ↔ 奇异。）

### C3 特征分解与 PCA 直觉
- **判分点**：① Av = λv：作用后方向不变、只缩放 λ 倍；② **推导链必须完整**：投影到单位方向 w 后方差 = wᵀCw，带约束 ||w||=1 最大化 → 拉格朗日 L = wᵀCw − λ(wᵀw−1)，对 w 求导得 Cw = λw → 最优 w 就是特征向量，方差值就是特征值，所以取最大特征值方向；只背「最大方差方向」不给推导 = 半过；③ 协方差矩阵实对称 → 谱定理：特征值全实、不同特征值的特征向量正交（重根也可选正交基）。
- **弱提示**：数据投影到方向 w 上，投影值的方差写成矩阵形式是什么？
- **中提示**：约束优化问题 max wᵀCw s.t. wᵀw=1，拉格朗日乘子法对 w 求导。
- **强提示**：∇(wᵀCw − λ(wᵀw−1)) = 0 直接给出 Cw = λw。
- **复习线变式**：量纲不同时（身高米、体重克）为什么先标准化再做 PCA？（方差大小会被单位劫持，大单位特征垄断第一主成分。）

### C4 SVD 几何与低秩截断
- **判分点**：① Vᵀ 先把输入旋转到一组正交基（右奇异向量），Σ 沿各轴按奇异值拉伸，U 再旋转到输出空间（左奇异向量）——「旋转×拉伸×再旋转」；② 奇异值排序是算法输出的约定，但本质是贪心：每个奇异值对应方向上「剩余能量最大」的方向，依次取走最大份额；③ 截断误差直觉：各奇异方向正交独立，重建误差的平方和 = 被丢弃奇异值的平方和，想误差最小就该丢最小的（Eckart–Young，定理名不算分，直觉必须有）。
- **弱提示**：把 Σ 想象成对角拉伸，U、Vᵀ 分别在前后干什么？
- **中提示**：A = Σ σᵢ uᵢ vᵢᵀ（秩一分量展开），丢掉哪几项损失最小？
- **强提示**：A_k = Σ_{i≤k} σᵢ uᵢ vᵢᵀ，误差 = Σ_{i>k} σᵢ²（正交分量互不干扰）。
- **复习线变式**：为什么 SVD 能用来降噪？（小奇异值方向往往承载噪声，截断即滤波。）

### C5 形状推导
- **判分点**：① (N,D)@(D,K) = (N,K)：内维 D 相消；b 形状 (K,) 广播成 (N,K)——广播规则是尾部维度对齐；② W@X 需要 W 的列数 K = X 的行数 N，一般不成立（除非 K=N，语义也不对）；③ 列主存放：Y' = Wᵀ @ X' + b 列广播，即 (K,D)@(D,N)=(K,N)（转置挂在 W 上，不是 X' 上）；④ 链：X(N,D) @ W1(D,H) = (N,H)，再 @ W2(H,K) = (N,K)，中间激活形状 (N,H)。
- **弱提示**：矩阵乘法合法的条件是哪两个维度相等？结果留下哪两个维度？
- **中提示**：广播看尾部维度；列主存放时把行主公式整体转置试试 (AB)ᵀ = BᵀAᵀ。
- **强提示**：行主 Y = XW+b；列主 Y' = Yᵀ = WᵀXᵀ + b = WᵀX' + b。
- **复习线变式**：(AB)ᵀ = BᵀAᵀ 为什么顺序要反？（用 (i,j) 元素定义推一步。）

### C6 神经网络=矩阵乘法链
- **判分点**：① 每层 y = σ(Wx+b)：线性部分是矩阵乘法，非线性是逐元素函数；无激活则 W2(W1x) = (W2W1)x，十层等价于单个矩阵——表达力塌缩成线性映射，这是「非线性是深度意义来源」的机制层回答；② 对角矩阵不混合维度：对角阵之积仍是对角阵，网络退化成「每个特征各自做仿射缩放」，特征间交互为零；③ 硬件快的原因：访存模式规则（连续内存、可预取）、内积天然向量化（SIMD/NEON 一条指令算多个乘加、GPU Tensor Core 一小块矩阵乘法单指令）——允许类比 Swift/ARM 的 SIMD 经验，但要落到「乘加密集+访存规则」两点上，只说「SIMD」不给机制 = 半。
- **弱提示**：把两层网络的公式展开，括号重新结合一下。
- **中提示**：矩阵乘法满足结合律——连续线性层的组合还是线性层。
- **强提示**：无激活：∏Wᵢ 就是一个矩阵；对角阵：(D2D1) 仍对角，特征间零耦合。

### F1–F3 争议焦点判分点
- **F1**：合格答案要承认两条路各有所长并给边界——几何派建立直觉但算不快、工程派上手快但容易「会算不懂」；复习场景合理路线是「工程骨架+按需补几何直觉」。只站一边不给代价 = 半过。
- **F2**：站「主干转 GEMM」但要给边界：变长序列/控制流依赖数据、稀疏结构、batch 太小时 kernel 启动开销占比高、逐元素激活本来就是 pointwise——这些场景显式/逐元素是对的。只喊「GPU 喜欢矩阵乘法」不给边界 = 半过。
- **F3**：教学用协方差+特征分解（直观对应 PCA 定义）；生产用对中心化数据直接 SVD，理由两条要至少中一条：① 显式构造 C = XᵀX 会把条件数平方（κ(C)=κ(X)²），数值上更脆；② N<D 时 C 是 D×D 巨大矩阵而 thin SVD 便宜。两条都给 = 过关。

## 二、代码题判分点与提示梯

### Q1 手写 matmul
- **判分点**：形状检查（内维不等报错可读）、三层循环正确、numpy 对拍过、耗时对比有真实数字且解释到位（解释器逐元素开销 + Python 对象装箱 vs C 循环 + BLAS 向量化 + 缓存友好；量级差 100 倍以上算正常）。
- **弱提示**：C[i][j] 的求和范围是什么？先写最朴素的三重循环。
- **中提示**：初始化结果矩阵时注意「每行独立新列表」（T1 复攻过的手艺）。
- **强提示**：`[[0.0]*cols_b for _ in range(rows_a)]`；循环序 i-k-j 可省一次读 B。
- **预期撞墙区**：形状检查写成 `rows_a != cols_b`；耗时对比忘记多次测量取平均。

### Q2 变换可视化
- **判分点**：三个矩阵写对（旋转 90°：[[0,-1],[1,0]]，注意逆时针；剪切：[[1,1],[0,1]]；投影 x 轴：[[1,0],[0,0]]）；断言 `T @ e1 == T[:,0]` 与 `T @ e2 == T[:,1]`；坐标打印体现形状变化（L 转了/歪了/扁了）。
- **弱提示**：旋转矩阵的列就是 e1、e2 旋转后的落点，先把 e1 转 90° 写到第一列。
- **中提示**：逆时针 90° 把 (1,0) 送到 (0,1)，把 (0,1) 送到 (−1,0)。
- **强提示**：R = [[cosθ, −sinθ],[sinθ, cosθ]]，θ=90° 代入。
- **预期撞墙区**：旋转方向写反（[[cos,sin],[−sin,cos]]）——用「e1 应落到 (0,1)」实测纠错。

### Q3 SVD 低秩近似
- **判分点**：合成矩阵确实是秩二主体+小噪声（u1v1ᵀ + u2v2ᵀ + ε）；奇异值谱前二大、其后贴地；重建公式 A_k = U[:,:k] @ diag(s[:k]) @ Vt[:k]；误差 k=1 明显、k=2 骤降、k≥3 只剩噪声量级；注释点破「主体只有两个秩一分量，k=2 恰好收完信号，再多收的是噪声」。
- **弱提示**：`np.linalg.svd` 返回的三个东西分别是什么形状？
- **中提示**：numpy 返回的第三个是 Vᵀ 不是 V；重建用切片 U[:,:k]、s[:k]、Vt[:k]。
- **强提示**：`A_k = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]`；误差 `np.linalg.norm(A - A_k)`。
- **预期撞墙区**：把 Vt 当 V 又转置一次；full_matrices 默认导致 U 形状 (m,m) 切片侥幸对但说不清。

### Q4 手写 PCA
- **判分点**：中心化正确（减均值）；协方差 C = X_cᵀX_c/(N−1)；`np.linalg.eigh` 结果**升序**——必须反转排序（翻车高发点）；方差解释比 λ₁/(λ₁+λ₂) 有数字；SVD 交叉验证用 |cos|≈1 或 `np.allclose(u1, ±v_eigh)`，符号相反要显式处理；文件头直觉一句话到位（「投影方差 = wᵀCw，最大方向就是最大特征值方向」）。
- **弱提示**：eigh 返回的特征值是什么顺序？第一主成分要最大还是最小？
- **中提示**：`idx = np.argsort(vals)[::-1]`，向量矩阵同步重排。
- **强提示**：交叉验证符号：`if u1 @ w1 < 0: u1 = -u1` 再 allclose。
- **预期撞墙区**：eigh 升序未反转（第一主成分取成最小方差方向）；符号相反误判为方向不一致。

## 三、人设预期漏洞（对拍用，见 [[01-学员人设卡.md|人设卡]]）

公式会对、直觉会错（C1 三重解释只知行内积、C2 奇异矩阵只会说「不可逆」）；多层形状推导会慌（C5 ④与列主转置）；PCA 推不出来（C3 ②只有结论）；SVD 纯学习区（C4 基本靠猜）；SIMD 类比是猜测（C6 ③只喊名词不给机制）。代码侧预期：Q1 对拍是算法功底舒适区大概率过；Q2 旋转方向撞墙；Q3 会调 API 但奇异值意义讲不清；Q4 教程记忆能写个大概、eigh 升序与符号大概率翻车。
