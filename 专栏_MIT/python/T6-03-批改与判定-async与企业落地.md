## 二、复攻销账（3 项）

1. **C2 补全（run_in_executor 边界）**：追问「同步 SDK 的阻塞调用丢线程池后，GIL 还挡不挡？」学员首攻：「IO 等待时 GIL 会释放，所以别的线程能跑」——对；追问「那 CPU 密集丢同一个池子呢」卡了一拍后答出：「没用，GIL 还握着，得 multiprocessing 或 ProcessPoolExecutor」。**过关**——盲区边界补全且与 F2 收官表述互相咬合。
2. **C4 变式（令牌桶 vs Semaphore）**：密卷复习线变式「限每秒请求数与限并发数分别用什么结构」。学员首攻：「速率要令牌桶——按固定速率往桶里放令牌，请求来了取一个，没令牌就等；并发用 Semaphore 只管在场数，管不了节奏」——方向对；追问「令牌桶的桶容量（burst）意味着什么」卡住，中提示后补出：「桶深=允许的突发上限，攒满桶的令牌可以瞬间花掉，所以限的是平均速率+突发上限两个参数」。**过关**——卡点真实（burst 语义缺位），补全后结构完整。
3. **C1 变式（loop 嵌套）**：密卷复习线变式「为什么在协程里再 asyncio.run 会报错」。学员首攻：「run 会新建一个 loop？loop 不能嵌套……因为当前线程已经有一个在跑的 loop」——方向对但没说到资源层；强提示后补出：「asyncio.run 要求自己是该线程 loop 的唯一主人：新建 loop、跑完、关掉；协程里调用时当前线程的 running loop 还在，run 检测到直接抛 RuntimeError——loop 是单实例资源，嵌套等于要求一根线程同时跑两个调度器」。**过关**。

复攻 3 项全销账，其中 2 项是变式题（复习线条款执行留痕）。
