# T3-01 教练密卷：概率论（仅教练分支，学员禁阅）

> 配套题干：`T3-01-教练出题-概率论.md`。本文件含判分点、弱/中/强三级提示、复习线变式题、失真自查清单。
> 复习线判定基准：**会算但无直觉 = 半过**；推导链断环按断环判；答得太顺 → 追加变式题降档。

## 一、概念题判分点与提示梯

### C1 疾病检测与基率谬误
- **判分点**：① 数值：P(病|阳) = 0.001×0.99 / (0.001×0.99 + 0.999×0.05) ≈ 0.019（约 1.9%）；② 角色指派：先验 = 患病率 0.1%，似然 = P(阳|病)=99% 与 P(阳|无病)=5%，后验 = P(病|阳)；③ 基率直觉：没病的人占 99.9%，5% 假阳性来自这个巨大基数，绝对人数（约 50/1000）碾压真阳性（约 1/1000）——「证据的强度干不过基数的悬殊」。
- **弱提示**：把 1000 个人摊开数人头——真阳性几个？假阳性几个？
- **中提示**：后验 = 真阳性人数 / (真阳性+假阳性)人数。
- **强提示**：分子 0.001×0.99，分母再加 0.999×0.05。
- **复习线变式**：若阳性者再测一次又是阳性，后验变多少？（第一次后验≈1.9% 成为新先验，再算一轮 ≈ 27%——两次独立证据把信念抬起来。）

### C2 似然与概率
- **判分点**：同一个式子、两种读法——P(x|θ) 把 θ 固定，看不同 x 的可能性，是 x 上的概率；L(θ|x) 把数据 x 固定，看不同 θ 对已见数据的支持度，是 θ 的函数但**不对 θ 归一**。观点层：概率回答「给定模型，什么数据会出现」；似然回答「给定已见数据，哪个模型更配」。似然不是 θ 的分布因为频率派观点下 θ 是固定常数不是随机变量（贝叶斯派乘以先验归一后才变成后验分布）。
- **弱提示**：把 θ 和 x 谁是「已经知道的」对调一下想想。
- **中提示**：似然的归一化常数依赖 x，对 θ 积分没有理由等于 1。
- **强提示**：概率是「模型→数据」的生成视角；似然是「数据→模型」的追责视角。
- **复习线变式**：MLE 和 MAP 的差别在哪一项？（MAP 多乘一个先验，等价于「带正则的 MLE」。）

### C3 伯努利 MLE
- **判分点**：完整链：L(p) = p^k (1−p)^(n−k) → ℓ(p) = k·ln p + (n−k)·ln(1−p) → dℓ/dp = k/p − (n−k)/(1−p) = 0 → k(1−p) = (n−k)p → p̂ = k/n。跳步或直接写结论 = 半过封顶。
- **弱提示**：独立事件的联合概率怎么组合？对数能把什么变成什么？
- **中提示**：ln p 的导数是 1/p，ln(1−p) 的导数是 −1/(1−p)。
- **强提示**：k/p = (n−k)/(1−p)，交叉相乘。
- **复习线变式**：为什么用对数似然不改变 argmax？（ln 单调递增。）为什么连乘在数值上危险？（下溢，Q2 代码会撞。）

### C4 MLE → 负对数似然 → 交叉熵
- **判分点**：三环都要有：① 标签独立同分布于类别分布，似然 = ∏ᵢ p_{yᵢ}（模型给真实类的预测概率连乘）；② −ln ∏ = Σᵢ −ln p_{yᵢ}，最大化似然 = 最小化负对数似然；③ p = softmax(z) 代入：−ln(softmax(z)_{y}) = −z_y + log Σⱼ exp(zⱼ)，即交叉熵（预测分布与 one-hot 真值分布之间的交叉熵）。只知「交叉熵是常用损失」= 未过；有一环 = 半过。
- **弱提示**：分类任务里「数据出现的概率」用什么分布写？每个样本贡献哪一项？
- **中提示**：独立样本的联合概率是连乘；MLE 最小化的是负对数似然。
- **强提示**：把 p_{yᵢ} = exp(z_{yᵢ})/Σⱼexp(zⱼ) 代入 −ln，逐项展开。
- **复习线变式**：标签平滑（label smoothing）在数学上动了哪一环？（one-hot 换成软目标，交叉熵的真值分布不再是点分布。）

### C5 softmax 数值稳定性
- **判分点**：① 机制层：float32 最大约 3.4e38，exp(89) 就溢出成 inf → inf/inf = nan；不是抽象「溢出」而是 exp 增长太快；② 不变性：exp(xᵢ−c)/Σⱼexp(xⱼ−c) = exp(xᵢ)e^{−c} / Σⱼexp(xⱼ)e^{−c}，公因子 e^{−c} 上下约掉；③ 负数区：全是大负数时 exp 集体下溢到 0，0/0 或相对精度丢光（最大项也被吞）。
- **弱提示**：float32 能装下的最大数是多少？exp 到多少就超了？
- **中提示**：分子分母同时提出一个公因子试试。
- **强提示**：c = max(x)；提出 e^c 后上下同除。
- **复习线变式**：log_softmax 为什么比 log(softmax(x)) 好？（先 log 域做 logsumexp，避免下溢后再取 log 的 −inf。）

### C6 σ/√N 与 CLT 出处
- **判分点**：① Var(Σxᵢ) = ΣVar(xᵢ) = Nσ²（独立性），Var(X̄) = Var(Σxᵢ/N) = Nσ²/N² = σ²/N，开根号即 σ/√N；② ML 真实出处至少两个：SGD 中 mini-batch 梯度是全批梯度的无偏估计且噪声 ∝ 1/√B（batch 越大越稳）；权重初始化的方差设计（Xavier/He）；集成学习平均多个模型降方差；测量/评估指标的置信区间。编造出处按半。
- **弱提示**：方差对独立变量可加；常数进方差要平方。
- **中提示**：X̄ = (1/N)Σxᵢ，先把 1/N 提出来。
- **强提示**：Var(aX) = a²Var(X)。
- **复习线变式**：为什么 batch size 翻倍不能把梯度噪声降一半以上？（噪声 ∝ 1/√B，翻倍只降 √2 倍——收益递减的根源。）

### F1–F3 争议焦点判分点
- **F1**：先验有用的场景：数据极少（冷启动）、有可靠领域知识（物理约束）、需要不确定性量化（医疗/风控）；负担场景：数据充足时先验被淹没、先验选错引入偏差、计算成本高。只喊学派口号不给场景 = 半过。
- **F2**：兼有两面——数学上「结果不变」（不变性可证），工程上「必须做」（不做会在 float32 溢出）。只答一面 = 半过。
- **F3**：采样优先的判据：解析积分不可得/太难、维度高（维数灾难）、只需数值答案不需闭式、模型是黑盒可重复采样；解析优先：低维有闭式、需要精确/可导、采样成本高于推导。学员刷题背景蒙特卡洛直觉应在线，判据给足 = 过关。

## 二、代码题判分点与提示梯

### Q1 蒙特卡洛 LLN/CLT
- **判分点**：收敛曲线至少 5 个量级采样点、末值贴近真期望；CLT 验证要有量化证据（样本均值的均值≈μ、标准差≈σ/√30，或分位数与正态对比误差）；「看起来像」不给分。
- **弱提示**：CLT 说的是「样本均值的分布」——你得重复很多次实验收集一堆均值。
- **中提示**：这堆均值的理论标准差是 σ/√N，先算出来再对拍。
- **强提示**：np.percentile(means, [2.5,50,97.5]) 与 N(μ, σ²/N) 的理论分位数对比。
- **预期撞墙区**：拿单次样本和 σ 对拍忘了除 √N；骰子分布的期望手算错。

### Q2 手写高斯朴素贝叶斯
- **判分点**：数据生成固定种子、训练/测试划分；先验=训练集频率；「朴素」= 给定类别后各维条件独立（联合似然 = 每维高斯相乘）；**必须对数域计算**（文件头解释连乘下溢）；准确率合理（两团分开时应 >95%）。
- **弱提示**：100 个 0.01 连乘在 float64 里还剩多少？
- **中提示**：log 把连乘变连加；比较后验只需比较 log 先验 + Σ log 似然。
- **强提示**：log N(x|μ,σ²) = −0.5·log(2πσ²) − (x−μ)²/(2σ²)。
- **预期撞墙区**：直接连乘下溢为 0 两类的后验全 0；忘了除以 2σ²。

### Q3 softmax 稳定性
- **判分点**：naive 版 float32 溢出证据真实（logits 取 100 量级即爆，exp(100)≈2.7e43 > 3.4e38）；稳定版同输入安然；一致性好（随机 logits 两版 allclose）；log_softmax 实现 = x − logsumexp，并说破「先 softmax 再 log」在下溢区得 log(0) = −inf。
- **弱提示**：float32 最大 3.4e38，exp 到多少爆？
- **中提示**：减最大值后最大指数是 exp(0)=1，其余全 ≤1。
- **强提示**：log_softmax(x) = x − max − log(Σ exp(x − max))。
- **预期撞墙区**：logits 不够大没触发溢出，反复调量级；numpy 默认 float64 不爆、忘转 float32。

### Q4 MLE 与交叉熵从零实现
- **判分点**：伯努利对数似然手写正确、网格搜索 p̂ 与频率一致到 0.01；ce() 含减最大值；三个性质验证齐全（正确类 logit↑损失↓、非负、均匀时 = log K）。
- **弱提示**：MLE 的 p̂ 理论上是 k/n——网格搜索的峰值应该正好落那。
- **中提示**：ce = −(z_y − log Σ exp(z))，先减最大值。
- **强提示**：均匀 logits 时 softmax = 1/K，−log(1/K) = log K。
- **预期撞墙区**：交叉熵符号写反得负损失；logits 里把正确类概率当 1−p 处理。

## 三、人设预期漏洞（对拍用，见 [[01-学员人设卡.md|人设卡]] 原文）

贝叶斯公式会套，但先验/似然/后验各自「是谁、更新了什么」说不利落（→C1 半过预期）；MLE 与交叉熵「MLE → 负对数似然 → 交叉熵」推导链推不全（→C3/C4 断链预期，C4 可能整链未过）；softmax 会当公式用，「为什么指数化、为什么减最大值」的数值稳定性理由说不出（→C5/F2 半过预期）；期望方差公式会算但二阶矩链路断（→C6①半过预期）。代码侧预期：Q1 蒙特卡洛是刷题舒适区大概率过；Q2 连乘下溢会撞墙；Q3 float32 触发溢出要调量级；Q4 交叉熵符号大概率翻车一次。
