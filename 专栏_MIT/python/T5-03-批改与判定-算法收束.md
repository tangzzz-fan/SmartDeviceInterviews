## 二、复攻销账（4 项）

1. **C1 变式（LFU）**：追加问「LFU 与 LRU 数据结构差在哪」。学员首攻：「每个键多记一个频率，淘汰时挑频率最低的」——追问「同频率里挑谁、怎么 O(1)」卡住（排序/堆都达不到 O(1)）。中提示「频率也要分桶」后补全：key→freq 哈希 + freq→双向链表桶 + min_freq 指针，同桶内按 LRU 序，淘汰取 min_freq 桶头，O(1)。**过关**——卡点真实（桶化维度缺位），补全后结构完整。
2. **C3 变式（树形打家劫舍）**：状态加什么维度。学员首攻直接到位：节点级二元状态 (rob, not_rob)，后序遍历向上合并，父节点偷 = Σ子不偷，不偷 = Σmax(子两态)。**过关**——树形是首攻过的，说明 DP 状态设计是真理解不是题面记忆。
3. **C5 变式（map vs 推导式）**：为什么 map(str, nums) 常快于推导式、何时反过来。学员首攻：「map 省了每轮的帧开销？」——方向对但没说到点。强提示后补全：map 的循环与函数调用都在 C 层连续执行，推导式每轮有字节码分发；但表达式一复杂（取属性/分支/多参），map 要么写 lambda（lambda 调用又把开销还回去）要么写不了，推导式反超。**过关**。
4. **C6 补层（选型视野）**：补「单调队列只能答窗口最值一类问题；堆更灵活——维护中位数可用对顶堆、维护多分位可扩展，代价是每步多个 log」。学员补述时主动接上了 Swift 侧类比（「像专用数据结构 vs 通用优先队列的取舍」）。**过关**。

复攻 4 项全销账，其中 3 项是变式题（条款①执行留痕）。
