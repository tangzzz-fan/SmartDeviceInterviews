# 学员须知（本文件只存在于学员分支）

> 你当前在学员分支 `feat/mit-swift-study-student`（对应 worktree：`.worktrees/swift-student`）。教练分支 `feat/mit-swift-study`（worktree：`.worktrees/swift-coach`）上放着 `T{n}-01-教练密卷`（提示梯 + 评分要点）以及旧作答/批改/费曼/解法代码——**本分支刻意不含这些内容**，这是防假学习的机制，不是遗漏。

## 你在这里能做什么

1. **看题干**：`T{n}-01-教练出题-<主题>.md`（共识模型 + 争议焦点 + 拷问题干，无提示无答案）。
2. **自推五模型**：先自己写 M1–M5，再对教练版，标注差异——先看模型表再复述 = 无效。
3. **闭卷作答**：写 `T{n}-02-学员作答-<主题>.md`——每题先写思考过程再给结论，附自评三档（有把握 / 半懂半猜 / 纯猜）。
4. **代码硬验证**：实现放 `代码/T{n}/`（目录已建好），`swift 代码/T{n}/Q*.swift` 跑通，输出贴回作答稿，文件头写撞墙记录。
5. **费曼写回**：主题自批通过后写 `T{n}-04-费曼草稿-<主题>.md`（含 OC/iOS 对照小节）。
6. **提交即留档**：作答与代码完成就 `git add -A && git commit`，你的台账在 `00-学习计划.md` 第五节（学员版留空，练完自填）。

## 纪律红线（违反 = 该轮作废重跑）

- **作答 + 自批完成之前，不许打开教练目录**（`.worktrees/swift-coach`）里的密卷、旧作答、批改、费曼或旧解法；
- 卡住要提示时，去密卷按 C1/C2 逐级看（弱→中→强），**看过的级数如实记进作答稿**，绝不直接抄旧作答；
- 自评必须诚实：「纯猜」不许写成「半懂」；能跑出结果但讲不出为什么 = 如实标半懂；
- 代码没跑起来 = 没验证，不许凭「应该能跑」交卷；
- 不许把教练目录的旧解法复制进 `代码/T{n}/` 充数。

## 流程速记

```
学员目录闭卷作答 + 代码实跑 + 提交
  → 教练目录对密卷自批（判 过/半过/未过，拆判分点）
  → 半过/未过回学员目录复攻（逐级提示）
  → 全过写费曼稿 → 提交
```

方法全文见 [[04-方法论基座-MIT三问与测试协议.md|方法论基座]]；角色分工与 worktree 用法见 [[使用说明书-角色指南.md|使用说明书]]。
