# 使用说明书：设计模式线学员/教练角色指南（worktree 版）

> 本文档说明 MIT-DesignPattern-Migration「教练 / 学员」两个角色的内容边界与日常循环。采用 **git worktree 双工作目录**：教练分支与学员分支各自挂一个独立目录，同时存在、互不干扰，不需要切换分支。
> 内容边界（三处齐全）：main / 教练侧 / 学员侧都持有完整内容——题干、密卷、参考解法、示例批改、示例费曼。防假学习从「物理不可见」改为「先闭卷后对照」的自律模式。

## 〇、一分钟看懂

一条学习线 = 一轮轮「拷问闭环」：**闭卷作答 → 代码实跑 → 对密卷自批 → 复攻销账 → 费曼写回**。内容拆放在两个 git 分支、两个 worktree 上：

| 工作目录 | 分支 | 归属角色 | 有什么 | 没什么 |
|---------|------|---------|--------|--------|
| `.worktrees/dp-coach` | `feat/mit-dp-study` | 教练 | 全量归档、`T{n}-01-教练密卷`（提示梯+评分要点+参考答案）、旧作答/批改/费曼、解法代码、台账 | 学员的新作答（你自己另写） |
| `.worktrees/dp-student` | `feat/mit-dp-study-student` | 学员 | 骨架文档（00–04）、题干、密卷、参考解法、示例批改/费曼、`学员须知` | 无（三处齐全，靠自律先写后对照） |

合并方向铁律（仅当你要把新作答归档回教练分支时）：**学员 → 教练**；教练 → 学员只允许选择性单文件同步题干。

## 一、首次搭建（一次性）

```bash
cd /Users/bigapple/Developments/MIT-Migration
git worktree add .worktrees/dp-coach   feat/mit-dp-study
git worktree add .worktrees/dp-student feat/mit-dp-study-student
```

之后两个目录各自独立打开：教练目录看答案与归档，学员目录闭卷实操。**日常不要在两个目录之间复制答案内容。**

## 二、学员循环（在 `.worktrees/dp-student`）

1. **领题**：读 `T{n}-01-教练出题-<主题>.md`（只有题干：共识五模型 + 争议三焦点 + 拷问题干，无提示无答案）。
2. **盘点存量 + 自推五模型**：先写「Swift 里我已经怎么解决这类问题」，再自推 M1–M5，对教练版标注差异——不许先看模型表再复述。
3. **闭卷作答**：写 `T{n}-02-学员作答-<主题>.md`——每题先写思考过程再给结论，附自评三档（有把握 / 半懂半猜 / 纯猜）。
4. **代码硬验证**：实现放 `代码/T{n}/`（目录已建好，内含 `.gitkeep`），`swift 代码/T{n}/Q*.swift` 实跑，文件头写撞墙记录，输出贴回作答稿。**没跑起来 = 没验证。**
5. **引入记账**：每个模式引入/拒绝的决定，写「问题-约束-代价」三行账。
6. **卡住要提示（可选）**：翻密卷按「弱 → 中 → 强」逐级看（密卷与参考解法同目录），**看过的级数如实记进作答稿**；禁止一上来就看强提示或参考答案。
7. **提交即留档**：`git add -A && git commit`。
8. **费曼**：全过后在学员分支写 `T{n}-04-费曼草稿-<主题>.md`（脱稿重推五模型 + 语言内建对照），再提交。

### 学员纪律红线（违反 = 该轮作废重跑）

- **先闭卷后对照**：作答完成前不许看密卷 / 参考解法 / 示例批改 / 示例费曼；对照过的题如实标注；
- 自评必须诚实：「纯猜」不许写成「半懂」；模式识别说不出「问题/约束」只说出名字的，如实标半懂；
- 参考解法只作对照，不许直接抄进 `代码/T{n}/` 充数；
- 代码没跑通不许写「已验证」；模式引入/拒绝没有记账不许写结论。

## 三、教练循环（在 `.worktrees/dp-coach`）

1. **对密卷自批**：学员作答完成后，打开对应 `T{n}-01-教练密卷`，按评分要点逐题判 过关 / 半过（拆判分点）/ 未过；概念看「问题-约束」是否讲清，代码看实跑输出与记账。
2. **记台账**：把判定写进 `00-学习计划.md` 第五节台账。
3. **复攻主持**：半过/未过的题，提示梯逐级给（弱→中→强），不许越级、不许直接贴参考答案。
4. **复核费曼**：学员交费曼稿后按评分要点复核，整轮收官。
5. **失真自查**：全题全对 = 人设失效；模式识别只背名字不讲 Forces = 识别失守；代码全靠旧解法抄也能判过 = 双通道失守。

## 四、归档与同步（可选）

- 学员分支新作答想并入教练分支归档：在教练目录 `git merge feat/mit-dp-study-student`（唯一合法方向）。
- 教练侧改了题干要同步给学员：在学员目录 `git checkout feat/mit-dp-study -- "MIT-DesignPattern-Migration/T{n}-01-教练出题-<主题>.md"` 单文件同步，随后自查：

```bash
git -c core.quotepath=false ls-tree -r --name-only HEAD | grep 密卷   # 必须为空
```

方法全文见 [[04-方法论基座-MIT三问与测试协议.md|方法论基座]]，台账见 `00-学习计划.md`（教练分支维护）。
