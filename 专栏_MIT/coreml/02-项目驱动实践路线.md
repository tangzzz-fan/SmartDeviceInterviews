# 项目驱动实践路线（代码通道载体）

> 定位：MIT-CoreML-Migration 的代码通道工程载体。每轮代码题挂靠一个 Phase 的可运行 Swift 脚本；验收判定仍以三问体系为准。
> 环境：macOS + Swift 6.x CLI；框架：CoreML / Vision / CreateML。真机 Neural Engine、相机、后台推送记「待真机验证」。

## Agent 角色定义

**身份**: Swift/iOS 开发者、正在系统化 CoreML 的 Agent  
**背景**: 会调 `prediction`，不熟资产管线与性能边界  
**目标**: 独立完成「造/转/装/跑/量」端侧闭环，并能论证何时不该上端侧  
**约束**: 结论必须可复现（脚本输出或度量表）；环境必须标注（CLI/模拟器/真机）
