# 学员须知（三处齐全版）

> CoreML 线采用「三处齐全」：参考解法、示例批改、示例费曼在 main / 教练侧 / 学员侧均可见。防假学习靠自律：**先闭卷作答，再对照参考，如实记录差距**。

## 你在这里能做什么

1. 看题干：`T{n}-01-教练出题-<主题>.md`
2. 闭卷作答：`T{n}-02-学员作答-<主题>.md`（自建）
3. 代码实跑：`代码/T{n}/`（参考解法同目录，先自己写）
4. 对照密卷与示例批改自批
5. 写自己的费曼稿
6. 提交留档；台账填 `00-学习计划.md` 第五节

## 纪律红线

- 先闭卷后对照；对照过的题标注「对照过」
- 自评诚实；只会调 API、讲不清契约的标半懂
- 代码没跑 = 没验证；真机项标「待真机验证」
- 端侧/云/内建选型无三行账，不许写结论

## 流程速记

```
闭卷作答 + 代码实跑 + 提交
  → 对照密卷/示例批改自批
  → 复攻 → 费曼 → 提交
```
