# T4-01 教练密卷：更新与多模态（仅教练分支/归档，学员禁阅）

> 本文件含弱/中/强三级提示、评分要点与参考答案。使用纪律：直接要答案 → 反问「这个模型训练时声明了可更新吗」。

## 一、概念题：提示梯与评分要点

### C1 如何判断模型能不能设备端更新
- 弱提示：设备端更新需要模型/训练框架支持什么（可更新模型声明、可写存储）？
- 中提示：`MLUpdatableModel` 与 `MLModelConfiguration` 的关系？训练时没声明能更新吗？
- 强提示：判断链：训练时用支持更新的框架（Create ML 可更新模板 / coremltools `.updatable`）→ 导出时声明可更新 → 运行时检查 `MLModel.updatable` → 用 `MLUpdateTask` 微调；任一环不满足 = 不能设备端更新。
- 评分要点：真懂特征：判断链完整；死记硬背典型：「MLUpdateTask 都能用。」
- 参考答案：训练声明 → 导出可更新 → 运行时检查 → MLUpdateTask；缺声明即不可。

### C2 个性化失败的三种产品表现
- 弱提示：样本太少会怎样？数据分布偏了会怎样？更新不可回滚会怎样？
- 中提示：过拟合/灾难性遗忘/更新后更差但无法回滚，分别是哪类失败？
- 强提示：三种表现：① 过拟合少数样本（个性化过头）；② 灾难性遗忘（学新忘旧）；③ 更新不可控（更差无法回滚）。产品要降噪 + 可回滚。
- 评分要点：真懂特征：三种表现 + 对应缓解；只有「效果不好」= 半过。
- 参考答案：过拟合、灾难性遗忘、不可回滚；缓解 = 有限样本 + 保留基线 + 双版本切换。

### C3 NLTagger vs CoreML 文本模型
- 弱提示：NLTagger 内建覆盖什么（分词/词性/命名实体/语言）？自定义模型什么时候才值得？
- 中提示：质量/控制权/体积/系统版本四维，对文本任务怎么打分？
- 强提示：NLTagger 免费、离线、体积零，先上；自定义只在内建质量不达标或要领域实体时；自定义 Transformer 端侧是重投入。
- 评分要点：真懂特征：先内建后自定义的标准 + 反例。
- 参考答案：默认 NLTagger；领域实体/质量不达标才自定义；先记账再上 Transformer。

### C4 flexible shape 要补哪些测试
- 弱提示：形状可变后，最短/最长/中间值都要测什么？
- 中提示：性能随形状怎么变？内存呢？
- 强提示：测试：边界形状（min/max/典型）、性能随长度的曲线、内存峰值、与固定形状的精度一致性。
- 评分要点：真懂特征：边界 + 性能 + 一致性三组测试。
- 参考答案：min/max/typical 三档 × 性能/内存/精度一致。

### C5 更新回滚清单
- 弱提示：回滚需要什么前提（旧模型可恢复、数据不污染、监控可观测）？
- 中提示：个性化后的数据要不要随回滚处理？
- 强提示：清单：旧版本可加载、更新可暂停、个性化数据可隔离、触发条件明确（指标下降/崩溃率）、灰度能力。
- 评分要点：真懂特征：≥4 项清单；只写「保留旧版」= 半过。
- 参考答案：可恢复旧版、可暂停更新、数据隔离、指标监控、灰度。

### C6 多模态（图+文）端侧的主要坑
- 弱提示：图与文的预处理/形状/时序怎么对齐？内存呢？
- 中提示：两个模型的输出怎么融合？输入缺失怎么处理？
- 强提示：坑：契约对齐（图+文特征）、时序对齐（异步结果）、内存（双模型常驻）、缺失模态降级、版本同步（双模型双版本）。
- 评分要点：真懂特征：≥3 个坑且能定位；死记硬背典型：「拼接特征向量就行。」
- 参考答案：契约/时序/内存/缺失降级/双版本同步五坑。

## 二、争议焦点参考立场

- D1 设备端个性化：隐私/弱网场景值得；否则云端管线更可控；期望要降噪。
- D2 NLP：NLTagger 优先；领域实体才自定义；Transformer 端侧重投入，先记账。
- D3 热更新：差分下载值得的条件 = 大模型 + 高频更新；审核边界要法务/产品确认。

## 三、代码题：评分要点与提示

### Q1 可更新判定清单
- 评分要点：打印检查项（声明/权限/存储/回滚）。
- 参考答案要点：清单 CLI 输出 boolean 列表。

### Q2 NLTagger 示例
- 评分要点：分词/词性跑通；输出「为何先不用 CoreML」账。
- 参考答案要点：`NLTagger` + `NLTagScheme.lexicalClass`；记账 = 质量够/体积零/系统自带。

### Q3 版本双缓冲
- 评分要点：内存中两版本切换可演示；旧版可恢复。
- 参考答案要点：`current` + `previous` 引用切换。

### Q4 多模态契约字段
- 评分要点：列出图+文融合的契约字段（图特征、文本特征、时序、缺失标记）。
- 参考答案要点：字段清单 + 缺失模态的默认值。

## 四、使用纪律
- 判分只认证据：检查清单输出、NLTagger 结果、双缓冲切换日志；「应该能」不算。
- 失真自查：把不可更新模型当可更新、没测边界形状 = 该题作废重跑。
