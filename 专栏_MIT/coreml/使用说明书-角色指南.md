# 使用说明书：CoreML 线学员/教练角色指南（worktree 版）

> 采用 **git worktree 双工作目录**。本线默认 **三处齐全**（main / 教练 / 学员均可见密卷与参考解法）：防假学习靠「先闭卷后对照」自律。

## 〇、一分钟看懂

| 工作目录 | 分支 | 角色 |
|---------|------|------|
| `.worktrees/coreml-coach` | `feat/mit-coreml-study` | 教练：全量 + 台账 |
| `.worktrees/coreml-student` | `feat/mit-coreml-study-student` | 学员：闭卷作答 + 代码实跑 |

合并方向铁律：学员 → 教练归档；教练 → 学员只同步题干时自查勿误带私货。

## 一、首次搭建

```bash
cd /Users/bigapple/Developments/MIT-Migration
git worktree add .worktrees/coreml-coach   feat/mit-coreml-study
git worktree add .worktrees/coreml-student feat/mit-coreml-study-student
```

## 二、学员循环（`.worktrees/coreml-student`）

1. 读题干 `T{n}-01-教练出题-*.md`
2. 自推五模型 → 闭卷作答 `T{n}-02`
3. `swift 代码/T{n}/Q*.swift` 实跑，输出贴回
4. 卡住按弱→中→强看密卷，记录级数
5. 对照示例批改/费曼格式，写自己的判定与费曼
6. `git add -A && git commit`

红线：作答前不看参考解法；CLI 结论不冒充 ANE；无边界账不许选型结论。

## 三、教练循环（`.worktrees/coreml-coach`）

按密卷评分要点判过/半过/未过；维护 `00-学习计划.md` 台账；复攻主持禁止越级贴答案。
