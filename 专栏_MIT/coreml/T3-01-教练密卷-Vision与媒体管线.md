# T3-01 教练密卷：Vision 与媒体管线（仅教练分支/归档，学员禁阅）

> 本文件含弱/中/强三级提示、评分要点与参考答案。使用纪律：直接要答案 → 反问「预处理对齐了吗」。

## 一、概念题：提示梯与评分要点

### C1 Vision 与 CoreML 的分工
- 弱提示：Vision 管什么（请求编排/图像处理/内置模型），CoreML 管什么（张量推理）？
- 中提示：VNCoreMLRequest 是谁的适配层？
- 强提示：Vision = 编排层（裁剪/方向/缩放/请求队列/内置模型）；CoreML = 执行引擎；VNCoreMLRequest 把 CoreML 模型包成 Vision 请求。
- 评分要点：真懂特征：分层清楚 + 适配关系；死记硬背典型：「Vision 就是 CoreML 的 Swift 接口。」
- 参考答案：Vision 管图像理解管线与内置模型，CoreML 管通用张量推理；VNCoreMLRequest 是桥。

### C2 图像预处理检查清单
- 弱提示：训练时对图像做了什么（尺寸/归一化/通道顺序/方向/颜色空间）？
- 中提示：推理时谁来做这些？不一致会发生什么？
- 强提示：清单：尺寸与缩放方式、归一化（mean/std）、通道顺序（RGB/BGR）、方向（EXIF）、颜色空间、位深、batch/裁剪。
- 评分要点：真懂特征：≥5 项且每项知道不一致后果。
- 参考答案：训练时预处理必须与推理完全一致；写进检查清单并在集成测试里断言。

### C3 orientation 错了的现象与验证
- 弱提示：EXIF 方向 ≠ UIImage.orientation ≠ 像素方向；错了的现象是什么？
- 中提示：验证方法：同一张图手动旋转后结果应一致？用固定方向图做断言。
- 强提示：现象 = 类别全错但置信度很高（静默失败）；验证 = 对同一内容不同 orientation 的图集做一致性测试。
- 评分要点：真懂特征：现象（高置信错类）+ 验证方法（orientation 一致性测试）。
- 参考答案：方向错 = 高置信度错类；用多 orientation 同内容测试集做回归断言。

### C4 内建 vs 自定义
- 弱提示：VNClassifyImageRequest 覆盖什么？质量/控制权/体积/系统版本四维怎么打分？
- 中提示：哪些信号（类目不符、要换骨干、输出格式）说明内建不够？
- 强提示：先内建（体积/维护白拿）；质量不达标或要控制权时上自定义；系统版本要求内建最低版本。
- 评分要点：真懂特征：四维标准 + 信号；死记硬背典型：「自训一定更好。」
- 参考答案：内建默认，四维不足再自定义；换骨干/自定义输出格式是强信号。

### C5 回调线程与 UI 更新
- 弱提示：VNRequest completion 在什么线程？UIKit 更新要求什么线程？
- 中提示：异步后回主线程的手段有哪些（DispatchQueue.main/await MainActor）？
- 强提示：completion 线程不保证；UI 更新必须主线程；用 `Task { @MainActor in ... }` 或 dispatch 回主。
- 评分要点：真懂特征：线程假设 + 回主线程手段。
- 参考答案：不假设回调线程，UI 更新显式回主线程。

### C6 扫证件三选一账
- 弱提示：端侧（离线/隐私/OCR 本地）、云（准确/更新快）、内建（VNDocumentCameraViewController + Vision 文本）——各写一档。
- 中提示：证件场景的硬约束：隐私（证件敏感）、离线（弱网）、更新频率？
- 强提示：证件敏感 → 端侧优先；内建 Vision 文本识别够用 → 先内建；自定义模型只在识别率不达标时上。
- 评分要点：真懂特征：三选一有依据 + 降级路径。
- 参考答案：默认内建 Vision 文本 + 端侧；不达标再自定义；云作为最后降级。

## 二、争议焦点参考立场

- D1 图像模型都包 Vision：默认包（编排白拿），纯张量/无图像语义场景例外。
- D2 test-time augmentation：延迟预算内可做投票；产品体验优先时不强上。
- D3 批处理：吞吐优先时批处理，产品体验优先时单张低延迟；用度量说话。

## 三、代码题：评分要点与提示

### Q1 VNClassifyImageRequest
- 评分要点：程序化 CGImage 生成；Top3 打印；无模型也可演示管线。
- 参考答案要点：`VNClassifyImageRequest` + `VNImageRequestHandler.perform`；结果取 confidence 排序。

### Q2 orientation 说明
- 评分要点：枚举打印 + 「错误方向会怎样」说明。
- 参考答案要点：`CGImagePropertyOrientation` 各值含义；错方向 = 高置信错类。

### Q3 VNCoreML 失败骨架
- 评分要点：加载失败错误处理骨架可编译演示；分层打印。
- 参考答案要点：`do { try VNCoreMLModel(for:) } catch { 分层 }`。

### Q4 管线三段耗时
- 评分要点：preprocess/infer/postprocess 三段计时输出；可 sleep 模拟。
- 参考答案要点：`ContinuousClock` 分段打点；输出三段占比。

## 四、使用纪律
- 判分只认证据：Top3 输出、orientation 说明、三段耗时；「大概会这样」不算。
- 失真自查：不跑 Vision 就说通了、把模拟器性能当真机 = 该题作废重跑。
