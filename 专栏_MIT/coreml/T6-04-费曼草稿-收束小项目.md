# T6-04 费曼草稿：收束小项目（示例）

> **示例文件**：本文件演示「整线收束的费曼/毕业报告」长什么样，用于格式参考，**不是真实产物**。

## 一、五模型脱稿重推

- **M1 先对拍再优化**：正确性基线先于性能；同一输入两次标签不一致，谈延迟无意义。
- **M2 端到端可回放**：数据、模型、预处理、度量可复现；别人拿同一清单能重跑。
- **M3 上线是决策**：体积/隐私/回滚/降级路径写进报告，Demo 成功 ≠ 可上线。
- **M4 拒绝也是产出**：证明「不该上 CoreML、继续走云或内建」同样过关。
- **M5 费曼可讲**：60 秒讲清架构与端侧/云边界，讲不清 = 还没收束。

## 二、端侧 vs 云对照（上线决策）

| 检查项 | 过关信号 | 拒端侧/改云信号 |
|--------|---------|----------------|
| 契约对齐 | 预处理与训练同参有证据 | 对齐测不稳 |
| 延迟 | 真机 P50 达标且有环境字段 | 仅模拟器数字 |
| 体积 | 量化账可结 | 掉点超阈值 |
| 隐私 | 威胁模型写完 | 必须上传才能准 |
| 回滚 | 触发条件可操作 | 「不行再看」式空话 |
| 降级 | 内建/云/关功能三选一 | 只有 happy path |

## 三、收尾报告（模拟数据）

- **值得上端侧**：表格分类器，真机 P50 12ms，量化后 3.1MB，掉点 0.8%，隐私要求离线。
- **负债已拒**：自定义 NLP Transformer（NLTagger 已覆盖）——体积 +28MB 换 0 产品增益。
- **降级路径**：模型加载失败 → 系统 VNClassify；弱机 → `.cpuOnly`；用户关相机权限 → 关功能。
- **三个结论**：① 对拍先于优化（T6 M1）；② 环境字段纪律（T5）；③ 拒绝也是交付（T6 M4）。

## 四、60 秒讲稿

「六轮下来，CoreML 对我不是 `prediction` 一行调用，是契约、资产、管线、更新、性能、上线决策整条链。先对拍再谈快；预处理与训练不一致等于没模型。端侧还是云，用延迟、隐私、体积、回滚、降级五本账，不是情怀。模拟器数字可以回归，不能上线。毕业标准：60 秒讲清架构和边界，并拿出一份别人能重跑的报告——包括『我们拒绝上 CoreML』的那种报告。」

## 五、自检三问

1. 被问「Demo 成功能否上线」能答（不能，缺环境/回滚/降级不算）。
2. 能讲给同事听：收尾报告三栏（值得/拒绝/降级）直接可用。
3. 诚实自查：T1 契约与 T5 模拟器纪律是我最深的两道疤，收束时强制复查过。
