# T2-03 批改与判定：模型资产与转换（示例）

> **示例文件**：本文件演示「教练按密卷判分」长什么样——基于一份模拟学员作答，用于格式与判定标准参考，**不是真实产物**。正式运行时请对你自己的真实作答另写一份批改。
> 判定依据：[[T2-01-教练密卷-模型资产与转换.md|T2 密卷]]。

## 一、学员作答摘要（模拟）

- C1：流水线画了「训练→导出→进 App」，缺验证、版本、回滚三节点。
- C3：说「Python acc=99% 就可以写进商店文案」，未提转换有损与端侧回归。
- C4：量化只盯体积，没写延迟与精度掉点。
- Q1：Create ML 表格分类器跑通，但验证指标漏打。
- Q3：量化账本只比体积，缺「是否值得」判定阈值。

## 二、首轮判定

### 概念通道（6 题）

| 题 | 判定 | 判分点拆解 |
|----|------|-----------|
| C1 | 半过 | 有训练/导出；缺验证·版本·回滚 |
| C2 | 过关 | Create ML 适合/不适合各一例，边界清楚 |
| C3 | 未过 | 把训练环境指标当发布结论；转换有损未提 |
| C4 | 半过 | 体积有；延迟与掉点未盯 |
| C5 | 过关 | 标签表与模型同版本；错位后果讲清 |
| C6 | 半过 | 「拒 CoreML」模板有字段；缺可操作阈值 |

### 代码通道（4 题）

| 题 | 判定 | 判分点拆解 |
|----|------|-----------|
| Q1 | 半过 | 训练跑通；验证指标未打印 |
| Q2 | 过关 | 导出路径 + 文件大小证据完整 |
| Q3 | 半过 | 能算体积差；无「值得」判定 |
| Q4 | 过关 | 模型语义版 + 预处理版 + App 最低版三元组 |

### 首轮总判定：**未过关**（概念 2过3半1未，代码 2过2半）

## 四、终审判定

复攻后概念 6 题全过、代码 4 题全过。**T2 过关。**
